### 1.2 精细标签来源详解

#### 来源A: 第三次全国国土调查（三调）— 最权威

**数据概况**:
- 标准时点: 2019年12月31日
- 组织单位: 北京市海淀区第三次全国国土调查领导小组办公室 + 北京市规划和自然资源委员会海淀分局 + 北京市海淀区统计局
- 技术手段: 卫星遥感影像、地理信息系统、"互联网+调查"
- 质量控制: 历时3年，参与调查200余人
- **数据规模: 汇集调查图斑约2.8万个，举证照片12.4万余张**

**海淀区三调地类数据**:

| 地类 | 面积 (公顷) | 占比 | 备注 |
|------|------------|------|------|
| 耕地 | 1372.92 | 3.19% | 水田150.09 + 水浇地969.74 + 旱地253.09 |
| 园地 | 1899.86 | 4.41% | 果园1851.60 |
| 林地 | 10668.49 | 24.77% | 乔木林地9762.11 |
| 草地 | 289.83 | 0.67% | |
| 城镇村及工矿用地 | 26156.18 | 60.72% | 城市用地15564.04 |
| 交通运输用地 | 1690.56 | 3.92% | |
| 水域及水利设施用地 | 902.99 | 2.10% | 河流水面179.17 |
| 其他土地 | — | — | |

**数据库成果**:
- 区级城乡一体化国土调查数据库
- 共享服务平台（可实现集成管理、动态入库、统计汇总、数据分析、快速服务、综合查询）

**获取路径**:
```
渠道1: 北京市规划和自然资源委员会海淀分局
  - 地址: 海淀区
  - 依据: 《非涉密基础测绘地理信息成果提供使用管理办法》
  - 方式: 提交申请，说明使用目的

渠道2: "天地图·北京"平台
  - 网址: 北京市地理信息公共服务平台
  - 提供: 分层地图数据（含地理国情要素图层）
  - 方式: 在线调用或离线服务申请

渠道3: 北京市政府数据开放平台
  - 网址: data.beijing.gov.cn
  - 提供: 部分汇总统计数据
```

**关键价值**:
- 2.8万个图斑 = **精细到地块级别**的标签
- 包含耕地坡度分级（2-6度、6-15度、15-25度、25度以上）
- 包含批准未建设的建设用地调查 = 可识别"批而未建"的变化潜力区域

---

#### 来源B: 年度国土变更调查 — 时间序列标签

**数据概况**:
- 北京市规划和自然资源委员会每年开展
- 基于三调成果，逐年更新
- **2025年最新数据**: 北京市规自委网站已发布"国土调查土地利用现状分类面积汇总表"（2025-11-12更新）

**获取路径**:
- 北京市规划和自然资源委员会官网 → 政务公开 → 数据统计 → 土地变更调查统计
- 或直接向海淀分局申请

**关键价值**:
- 年度变更 = **可直接用于验证2025-2026年的变化**
- 包含耕地流向分析（耕地→林地、耕地→建设用地等）

---

#### 来源C: 永久基本农田保护数据 — 耕地变化核心

**数据概况**:
- 海淀区永久基本农田保护面积: **约667公顷（约1万亩）**
- 主要分布: **上庄镇、西北旺镇、温泉镇、苏家坨镇**
- 涉及: 5镇28个村
- 2022年修改后: 约6.56平方公里

**获取路径**:
- 北京市规划和自然资源委员会
- 海淀区农业农村局（"村地区管"系统相关）

**关键价值**:
- 任总关注"耕地变化" = **永久基本农田是核心监测对象**
- 可精确定位哪些地块是"不可占用"的耕地，变化检测的优先级最高

---

#### 来源D: 地理国情普查/监测 — 公开精细数据

**数据概况**:
- 2015年全国地理国情普查
- 历年地理国情监测更新
- 数据内容: 地表覆盖分类数据、地理要素数据

**获取路径**:
- 天地图·北京 → 分层地图数据 → 地理国情要素图层
- 自然资源三维立体时空数据库（部分数据）

**关键价值**:
- 无需政府协调，可立即获取
- 可作为**过渡标签**启动训练

---

#### 来源E: 天地图·北京 — 即时可用

**数据概况**:
- 北京市地理信息公共服务平台
- 矢量电子地图、影像电子地图、分层地图数据
- 包含: 地理国情、文物、红色景点等要素图层

**获取路径**:
- 在线服务接口（免费注册调用）
- 离线服务申请

**关键价值**:
- **零门槛获取**，可立即用于项目启动
- 影像电子地图按季度更新，可作为可视化底图

---

#### 来源F: 已有学术数据 — 辅助验证

**已知研究**:
- 多篇论文对海淀区进行土地利用分类（2018-2021）
- 分类体系: 建设用地、林地、耕地、水体、裸地
- 数据源: Sentinel-2

**获取方式**:
- 联系论文作者获取分类结果
- 作为独立的精度验证参考
