# 改动指令：Dataset目标帧从固定第0帧改为随机采样

## 改动背景

当前 `src/data/dataset.py` 的 `_get_item()` 方法中，自编码器重建目标总是取输入帧的第0帧（排序后的最早日期）。这导致：
- 模型过度拟合到最早日期的帧
- 当月其他帧完全没有被重建loss监督到
- 与AEF论文"randomly selects one frame from the input sequence"的设计不符

## 改动内容

### 文件
`src/data/dataset.py`

### 当前代码（第1048-1056行附近）

```python
            elif tgt_name in ("s2", "s1", "landsat"):
                # Round 2: 动态目标从 month_B 加载（跨时相重建）

```

### 改成

```python
            elif tgt_name in ("s2", "s1", "landsat"):
                # Round 2: 动态目标从 month_B 加载（跨时相重建）
                data = None
                if month_b == month_a:
                    # 同月：从可用输入帧中随机采样1帧作为目标
                    s_idx = self.input_sources.index(tgt_name)
                    # 收集该源所有有效的帧索引
                    valid_indices = [i for i in range(self.max_frames) if source_mask[s_idx, i]]
                    if valid_indices:
                        random_idx = random.choice(valid_indices)
                        data = source_frames[s_idx, random_idx].copy()
                else:
                    # 跨月：从 month_B 加载目标帧，同样随机采样1帧
                    tgt_frames, tgt_ts = self._load_monthly_frames(patch_id, tgt_name, year, month_b)
                    if len(tgt_frames) > 0:
                        random_idx = random.randint(0, len(tgt_frames) - 1)
                        data = tgt_frames[random_idx]
```

## 注意事项

1. **不需要改其他文件**。这个改动只在dataset采样层面，不影响model、trainer、loss的计算逻辑。
2. **不需要重新计算统计量**。这个改动不影响预处理流程。
3. **需要删除旧缓存**。因为缓存中保存的是已经采样好的target，改了采样逻辑后旧缓存可能不一致。
   ```bash
   find /workspace/outputs -name "dataset_cache_*.pt" -delete
   ```
4. **git commit + push**。
