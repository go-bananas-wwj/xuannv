## 三、NPY 数组数据（需后端转换后供前端使用）

> NPY 是 NumPy 二进制格式，**前端无法直接读取**，需要后端服务或构建时转换为 PNG/JSON/GeoTIFF。

### 3.1 Embedding 数据（4,000 个文件）

| 目录 | 文件数 | 用途 |
|------|--------|------|
| `data/embeddings/v2_baseline_10ep/` | 500 | V2 Baseline 实验的 patch 级 embedding |
| `data/embeddings/v2_high_kappa_10ep/` | 500 | V2 High Kappa 实验 |
| `data/embeddings/v2_original_10ep/` | 500 | V2 Original 实验 |
| `data/embeddings/v2_vicreg_25_10ep/` | 500 | V2 VicReg 25 实验 |
| `data/embeddings/v2_vicreg_bilateral_10ep/` | 500 | V2 VicReg Bilateral 实验 |
| `data/embeddings/v2_vicreg_recon_10ep/` | 500 | V2 VicReg Recon 实验 |
| `data/embeddings/v2_vicreg_recon_batch_10ep/` | 500 | V2 VicReg Recon Batch 实验 |
| `data/embeddings/v2_vicreg_uniform_10ep/` | 500 | V2 VicReg Uniform 实验 |

> 每个 `.npy` 对应一个 patch 的空间 embedding map，形状约 `[H, W, D]`（D=256）。
> **可视化场景**: embedding 热力图、PCA/t-SNE 降维可视化、相似度图。

### 3.2 变化检测掩码（1,696 个文件）

| 目录 | 文件数 | 用途 |
|------|--------|------|
| `data/change_masks/june/` | 424 | 6月-8月变化掩码 |
| `data/change_masks/aug/` | 424 | 8月-10月变化掩码 |
| `data/change_masks/september/` | 424 | 9月变化掩码 |
| `data/change_masks/october/` | 424 | 10月变化掩码 |

> 每个 `.npy` 形状约 `[H, W]`，值为 0/1 二值掩码。
> **可视化场景**: 叠加在卫星影像上的变化高亮区域。
> **注意**: 变化区域非常稀疏（june 47个patch有变化，aug 仅21个）。

### 3.3 标签数据（~1,272 个文件）

| 目录 | 文件数 | 用途 |
|------|--------|------|
| `data/labels/landuse/` | ~424 | 土地利用标签 |
| `data/labels/building/` | ~424 | 建筑物标签 |
| `data/labels/water/` | ~424 | 水体标签 |

> **可视化场景**: 语义分割标签图、与模型预测对比。

## 六、前端团队建议

### 优先级 1：立即可展示
- PNG 图片（数据分布、学术图表）
- JSON 统计（变化掩码统计、实验状态看板）

### 优先级 2：需简单后端 API
- 读取 NPY → 转换为 PNG 热力图或 GeoJSON
- 读取标签 → 与影像叠加展示

### 优先级 3：深度可视化
- Embedding 的 t-SNE/UMAP 降维散点图
- 时序变化对比滑块（Before/After）
- 多实验 AUC 对比图表

---

## 七、注意事项

1. **模型权重 (.pt) 不包含在本清单中**，如需要请单独说明。
2. **Pipeline 目前 8/8 实验 embedding 提取失败**，如前端需要展示 embedding 数据，需先修复提取流程。
3. **所有 NPY 文件都是空间数据**，如需要做地图叠加，需配合各 patch 的地理坐标（extent/bounds）。
4. **变化掩码极度稀疏**，aug 时期仅 21/424 个 patch 有变化，前端设计时需考虑"无变化"的默认展示。
