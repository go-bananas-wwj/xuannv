# 专利申请技术交底书

## 一、发明名称

基于预归一化反坍缩与双窗口时序对比的遥感嵌入学习方法

## 二、技术领域

本发明属于遥感影像处理与深度学习技术领域，具体涉及一种多时相、多源遥感数据的自监督嵌入学习方法。

## 三、背景技术

遥感影像的时序分析是监测地表动态变化的重要手段。传统方法依赖人工设计特征或监督学习，需要大量标注数据，对季节变化、云遮挡等干扰敏感。

近年来，自监督基础模型成为遥感领域的热点方向。谷歌 DeepMind 发布的 AlphaEarth Foundations（AEF）是代表性工作，采用 von Mises-Fisher 分布将多源时序遥感数据压缩为单位球面上的嵌入向量，通过重建任务和教师-学生一致性机制学习通用地表表征。AEF 使用 512 块 TPU v4 训练 56 小时，数据量达 30 亿帧，覆盖全球 500 万个站点。

AEF 及类似方法存在一个共性问题：嵌入坍缩。模型在训练中将所有输入映射到嵌入空间的相近区域，不同时间窗口、不同地表状态的嵌入向量几乎相同，丧失了时间判别能力。这种坍缩使模型无法区分变化与未变化的地表区域，限制了变化检测等下游应用。

现有防止坍缩的技术包括三类：

对比学习（SimCLR、MoCo）通过正负样本对拉开距离，但依赖大批量或记忆库；非对比方法（Barlow Twins、VICReg）通过去相关和方差约束防止坍缩，通常在 L2 归一化后的球面上计算，梯度传递受限；批均匀性损失在批次维度上鼓励样本分散，但效果依赖批次大小和数据多样性。

本发明的出发点在于：现有方法在 L2 归一化后的球面上计算反坍缩损失时，梯度经过雅可比矩阵变换，嵌入接近坍缩时该矩阵接近零，梯度消失。因此，需要在归一化前的原始幅度空间中直接施加反坍缩约束，同时引入显式的时间对比信号，使嵌入对时间变化敏感。

## 四、现有技术的缺点及本发明所要解决的技术问题

### 1. 主要技术问题

现有遥感嵌入学习方法存在以下不足。

嵌入坍缩导致的梯度消失。现有方法在 L2 归一化后的单位超球面上计算反坍缩损失，梯度需经过归一化操作的雅可比矩阵变换。嵌入趋于坍缩时，该矩阵接近奇异，梯度急剧衰减，反坍缩损失失效。

时间敏感性不足。现有方法主要依赖重建任务隐式学习时序信息，缺乏显式约束迫使不同时间窗口的嵌入产生差异。嵌入向量对地表时间变化不敏感，无法直接用于无监督变化检测。

### 2. 次要技术问题

小批量场景下的反坍缩效果差。现有批均匀性损失假设批次内样本来自不同地理区域、互不相关。在小数据场景（如单一城市 400 余个观测点）中，批次内样本高度相关，批均匀性的负样本假设不成立。

静态目标干扰时序学习。现有方法将 DEM、土地覆盖等静态数据与动态遥感数据同等对待作为重建目标，静态目标的时间无关性干扰模型对时间动态的建模。

### 3. 技术效果

本发明预期达到以下效果：

嵌入均匀性指标从 -0.5 提升至 -2.0 以下；变化检测 AUC 从随机水平（0.5）提升至 0.68 以上；在仅有 400 余个观测点的小数据场景下仍可训练出时间敏感的嵌入；无需人工标注即可实现变化检测能力。

## 五、本方案详细阐述

### 5.1 整体架构

本发明包括以下核心模块。

多源编码器分别对 Sentinel-2（光学）、Sentinel-1（SAR）、Landsat（光学）三类时序遥感数据进行独立编码，将各源的通道和空间分辨率映射到统一的潜在空间。

时空精度块（STP Block）采用三路并行算子处理编码后的特征，包括时间轴自注意力（1/8 分辨率）、空间自注意力（1/16 分辨率）和精度保持卷积（1/2 分辨率），通过空间金字塔重采样进行信息融合。

VMF 瓶颈层将 STP 块输出的特征图通过 1×1 卷积压缩到嵌入维度。训练阶段保留原始幅度，推理阶段施加 L2 归一化和 VMF 噪声，输出单位球面上的嵌入向量。

条件解码器为每个目标源配备源特定的隐式解码器，从嵌入向量中重建原始输入帧。

### 5.2 预归一化反坍缩方法

本发明的核心创新是训练阶段跳过 L2 归一化，在原始幅度空间中计算全部反坍缩损失。

设嵌入向量为 x ∈ R^D，传统方法先计算 u = x / ||x||，然后在 u 上计算均匀性损失。此时损失的梯度为：

∂L/∂x = (∂L/∂u) · (I - uu^T) / ||x||

嵌入坍缩时，||x|| 趋于一致，(I - uu^T) 的行列式接近零，梯度趋于消失。

本发明改为直接在 x 上计算反坍缩损失，采用四重约束。

原始均匀性损失对 x 进行零均值和单位方差标准化后，在欧氏空间中计算成对 RBF 核的均匀性。自适应温度参数 t = 2/D，确保指数项在正常范围，梯度永不消失。良好分散时损失约 -4，完全坍缩时约 0。

去相关损失计算 x 维度间的互相关矩阵，最小化非对角元素的平方和，同时使对角元素接近 1。

方差正则化对每个维度的标准差施加 hinge 约束，低于阈值时产生惩罚，防止维度坍缩到零点。

瓶颈正交性损失对 1×1 卷积的权重矩阵施加正交约束，在嵌入坍缩时仍可通过权重梯度提供非零信号。

### 5.3 双窗口时序对比方法

本发明的另一核心创新是引入双窗口采样和时序对比损失，显式约束嵌入对时间变化敏感。

训练过程中，对同一地理区域的两个不重叠时间窗口分别编码，得到 emb_w1 和 emb_w2。时序对比损失包括以下四项。

全局时序对比损失对 emb_w1 和 emb_w2 的全局平均向量计算余弦相似度，使用 hinge 损失约束相似度低于目标阈值（如 0.2）。该阈值表示：即使同一地点，不同时间窗口的嵌入也应保持足够差异。

像素级时序损失在 emb_w1 和 emb_w2 的每个空间位置上独立计算余弦相似度，采用自适应空间加权策略：变化区域（图像差异大）要求嵌入差异更大，未变化区域要求嵌入保持相似。

间隔感知时序损失根据两个窗口的时间间隔动态调整目标相似度。间隔越小要求相似度越高，间隔越大允许差异越大。

反斜对角 InfoNCE 损失将批次中对角线位置的样本对（即同一地点的两个窗口）视为负样本，鼓励批次内不同地点的窗口嵌入互相区分。

### 5.4 教师-学生一致性机制

训练时采用教师-学生框架。教师模型接收完整输入序列，学生模型接收扰动输入。一致性损失要求教师在 L2 归一化空间中的嵌入与学生嵌入的余弦相似度接近 1。

扰动策略包括：源级别丢弃（Sentinel-1 和 Landsat 以 30% 概率完全丢弃）；帧级别丢弃（Sentinel-2 以 50% 概率随机丢弃帧，其他源以 30% 概率丢弃）；前后截断（以 25% 概率丢弃序列的前半段或后半段）。

### 5.5 静态目标弱化策略

将 DEM 等静态目标的重建权重降低至动态目标的 5%，使模型优先学习需要时间信息才能重建的动态目标，减少对时间无关特征的依赖。

## 六、本申请的关键点和欲保护点

### 1. 主要发明点

在预归一化空间中计算反坍缩损失的方法，包括：在原始幅度向量上直接计算 RBF 均匀性损失，自适应温度 t = 2/D；与去相关损失、方差正则化、瓶颈正交性损失的组合使用；训练阶段跳过 L2 归一化、推理阶段恢复 L2 归一化的两阶段策略。

### 2. 次要发明点

双窗口不重叠采样方法：对同一地点抽取两个不重叠的时间窗口，分别编码后计算时序对比损失。

多粒度时序对比损失组合：全局 hinge 损失、像素级自适应加权损失、间隔感知损失、反斜对角 InfoNCE 的联合使用。

教师-学生一致性中的多阶段扰动策略：源丢弃、帧丢弃、前后截断的联合使用。

静态目标弱化方法：降低静态数据重建权重，优先学习时间敏感特征。

## 七、与现有技术相比的技术优点

本发明解决了 L2 归一化导致的梯度消失问题。现有方法在归一化后计算反坍缩损失，梯度经过雅可比矩阵变换后趋于消失。本发明在归一化前直接计算，反坍缩梯度始终非零。

本发明显式学习时间敏感性。现有方法依赖重建任务隐式学习时序信息，时间敏感性是涌现的、不可控的。本发明通过双窗口时序对比损失显式约束嵌入对时间变化敏感，可直接用于变化检测。

本发明适用于小数据场景。raw uniformity 损失不依赖批次内的负样本假设，在单一城市 400 余个观测点的小数据场景下仍可有效防止坍缩。

本发明降低静态目标干扰。通过降低静态数据重建权重，避免模型学到时间不重要的偏差。

## 八、替代方案

反坍缩损失可采用 Coding Rate Loss（基于最大编码率降低理论）替代 raw uniformity，通过 log det 体积最大化约束嵌入空间。

时序对比损失可采用 NT-pair Loss（Contrast All The Time），沿完整时间维度并行对比所有时间步，而非仅对比采样窗口。

教师-学生框架可采用共享参数策略（AEF 原文方式），教师和学生使用完全相同的参数，仅输入不同，替代当前的 EMA 动量更新策略。

双窗口采样可扩展为多窗口采样，同时对比三个或更多时间窗口的嵌入。
