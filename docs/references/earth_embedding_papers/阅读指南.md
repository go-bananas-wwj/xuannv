# Earth Embedding 论文阅读指南

> 按照与 xuannv_embdding 项目的相关性和重要程度划分

---

## 📖 01_需要精读（9篇）

### 🔴 第一优先级：与 xuannv 直接可比/基线

| 论文 | 为什么必读 |
|------|-----------|
| **AEF原版_AlphaEarth Foundations.pdf** | ⭐⭐⭐ **直接基线**。xuannv 是 AEF 的独立改进版。必须精读原版架构、损失函数（reconstruction + consistency + text-contrastive + batch-uniformity）、VMF 球面嵌入、时空 Precision 编码器 |
| **AEF农业评估_指出时间敏感性问题.pdf** | ⭐⭐⭐ **xuannv 改进动机的直接来源**。该论文系统评估了 AEF 在农业下游任务中的表现，**明确指出了 AEF 的"limited time sensitivity"问题**。这正是 xuannv 双窗口 + 时序对比损失要解决的核心问题 |

### 🟠 第二优先级：技术路线高度相似

| 论文 | 为什么必读 |
|------|-----------|
| **Presto_像素级轻量多传感器MAE.pdf** | ⭐⭐⭐ **像素级 embedding + 多传感器 + MAE**。仅 0.4M 参数却能在多种下游任务中与大型 ViT 竞争。Presto 证明了像素级时间序列表示学习的可行性，对 xuannv 的轻量化和高效推理有重要参考价值 |
| **DOFA_动态多传感器统一表示.pdf** | ⭐⭐⭐ **动态权重 + 任意传感器**。DOFA 使用波长条件超网络动态生成 patch embedding 权重，让单一 Transformer 处理任意波段数的任意传感器。这与 xuannv 的 SensorEncoderBank + STPBlocks 的多源融合思想高度相通 |
| **TerraMind_生成式多模态基础模型_ICCV2025.pdf** | ⭐⭐⭐ **任意模态到任意模态生成**。IBM+ESA 的最新工作，双尺度表示 (token + pixel)、Thinking-in-Modalities (TiM)。TerraMind 的多模态重建目标与 xuannv 的 7 目标重建（S2/S1/Landsat/DEM/WorldCover/DynamicWorld/JRCWater）设计哲学一致 |
| **Prithvi-EO-2.0_时序ViT_NASA+IBM.pdf** | ⭐⭐⭐ **时序 ViT + MAE + 位置/时间嵌入**。NASA+IBM 的第二代模型，在 420 万 HLS 时间序列样本上预训练。与 xuannv 同样基于时空 Transformer，Prithvi-EO-2.0 的时间和位置嵌入增强值得参考 |

### 🟡 第三优先级：领域标杆/前沿

| 论文 | 为什么必读 |
|------|-----------|
| **OlmoEarth_多模态时空基础模型.pdf** | ⭐⭐⭐ **最新多模态时空基础模型**（2025-11）。Allen AI 的工作，在 24 个任务中 15 个 SOTA。其新颖的自监督学习、掩码策略和损失函数设计对 xuannv 的损失函数优化有启发 |
| **SatMAE_时序多光谱MAE_NeurIPS2022.pdf** | ⭐⭐ **时序+多光谱 MAE 的奠基工作**。分组掩码策略、通道-空间关系学习。SatMAE 是多光谱遥感 MAE 的开创性工作，理解其设计有助于优化 xuannv 的掩码策略 |
| **ScaleMAE_尺度感知MAE_ICCV2023.pdf** | ⭐⭐ **多尺度表示学习**。拉普拉斯金字塔解码器，处理 0.1m-30m 多分辨率。虽然 xuannv 目前固定 10m 分辨率，但 ScaleMAE 的尺度感知思想对未来扩展有价值 |

### 综述与概念框架

| 论文 | 阅读目的 |

| 论文 | 阅读目的 |
|------|----------|

### 特定方向模型

| 论文 | 阅读目的 |
|------|----------|
| **CROMA_雷达光学对比学习_NeurIPS2023.pdf** | SAR+光学联合预训练的对比学习 + MAE 结合方案。对 xuannv 的 S1 SAR 分支优化有参考意义 |
| **SatCLIP_位置嵌入_AAAI2025.pdf** | 位置-卫星图像联合嵌入。了解位置编码的另一种实现方式 |
| **EarthPT_时序基础模型.pdf** | 时间序列专用的地球观测基础模型。了解时序表示学习的另一种路径 |
| **Major TOM_全球密集Earth Embedding.pdf** | 全球密集 embedding 数据集。了解 embedding 产品化的实践 |

### AEF/xuannv 下游应用

| 论文 | 阅读目的 |
|------|----------|
| **Earth Embeddings城市信号预测_AEF对比.pdf** | 对比 AEF / Prithvi-EO-2.0 / Clay-v1.5 三种 Earth Embedding。了解 AEF 与其他主流模型的对比表现 |
| **FUSAR-GPT_AEF下游应用.pdf** | AEF embedding 在 SAR 图像理解中的特征补偿应用 |
| **Prithvi滑坡制图_地理泛化性.pdf** | Prithvi-EO-2.0 在滑坡制图中的地理泛化性评估。了解 FM 的跨域迁移能力问题 |
| **基础模型在可持续发展目标上的评估.pdf** | 多种基础模型（DOFA/GFM-Swin/Prithvi/SpectralGPT/ScaleMAE/SSL4EO-S12）在 SDG 任务上的系统评估 |
| **Clay+LoRA快速适配分割.pdf** | Clay 模型 + LoRA 快速微调到洪水分割任务。了解 FM 高效适配的方法 |
| **Earth AI_Google多任务预训练.pdf** | Google 的遥感多任务预训练（MAE+MTP）。了解多任务预训练的最新实践 |
| **BFM_十亿参数遥感基础模型.pdf** | 超大参数规模遥感 FM 的探索。了解 scaling law 在遥感领域的适用性 |

## 🎯 建议阅读顺序

### 阶段一：建立基线（1-2天）
1. **AEF原版** — 理解 xuannv 改进的原版架构
2. **AEF农业评估** — 理解原版的问题，明确改进动机
3. **遥感基础模型全面综述** — 建立领域全景认知

### 阶段二：技术对标（2-3天）
4. **Presto** — 像素级轻量化的标杆
5. **DOFA** — 多传感器动态融合的方案
6. **Prithvi-EO-2.0** — 时序 ViT 的标杆
7. **TerraMind** — 生成式多模态的最新方案

### 阶段三：前沿拓展（1-2天）
8. **OlmoEarth** — 最新多模态时空模型
9. **SatMAE** — 多光谱 MAE 奠基工作
10. **ScaleMAE** — 多尺度感知

### 阶段四：按需参考
- 其余 16 篇根据具体研究方向（变化检测、分割、分类、benchmark 等）选择性阅读

## 📝 精读笔记建议

对每篇精读论文，建议记录：

| 维度 | 记录内容 |
|------|----------|
| **架构** | 编码器结构、输入输出格式、嵌入维度、分辨率 |
| **预训练** | 自监督策略（MAE/对比学习/生成式）、损失函数、数据规模 |
| **多传感器处理** | 如何处理 S1/S2/Landsat 等不同传感器、不同波段数 |
| **时间建模** | 如何处理时序数据、时间编码方式、时间敏感性 |
| **与 xuannv 对比** | 哪些方面 xuannv 更好？哪些方面可以借鉴？ |
| **可迁移技术** | 哪些组件/损失/策略可以直接或修改后用于 xuannv？ |
