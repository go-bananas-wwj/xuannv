## 关键发现汇总

### 数据量分布
- 哈尔滨: 424p, S2=9,321(云筛选), S1=~18k, Landsat=~19k
- 大庆: 309p, S2=45,350, S1=28k, Landsat=52k
- 海淀: 400p, S2=41,077, S1=35k, Landsat=50k
- 大庆/海淀S2未做云筛选，帧数是哈尔滨的5~7倍

### 预处理
- S2/Landsat: log(x+1)/10 → z-score → ±6σ clip（对齐AEF论文）
- S1: clip[-30,10]dB → z-score → ±6σ clip
- WC/DW: 类别映射 → One-Hot（不做z-score）
- DEM/JRC: z-score → ±6σ clip

### 统计量时机
- **变化前**的原始统计量（read_tif后直接计算，不调normalize）

### Dataset采样
- 月度采样: 样本=(patch, year, month)
- 输入: 当月每源所有帧（最多32张），不是只有1张
- 目标: 每源1张（自编码器或跨时相）

### 双窗口
- 4种模式: random_split(默认), adjacent_month, non_overlap, mixed_scale
- 控制attention只能看到窗口内的帧

### Target Loss
- V14只剩4个目标: S2/S1/Landsat/DEM
- WorldCover/DynamicWorld/JRC Water已移除
- DEM权重仅0.05
