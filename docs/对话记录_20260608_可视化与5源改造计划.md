**决策**：s1 和天仪 SAR **同时保留**，作为两个独立输入源。

### 2. 时间筛选

- **范围**：2025-12-01 至 2026-04-30
- 各源只保留该时间窗口内的帧
- Planet 数据原本就约 6 帧（2025-12 ~ 2026-04），筛选后可能剩 3-6 帧

### 3. 可视化布局（合并为一张大图）

```
Row 1: [s1] [s2] [tianyi_sar] [landsat] [planet]  ← 5个输入源的有效帧
Row 2: Student Embedding (PCA RGB)                   ← 模型输出 64D → PCA → RGB
Row 3: AEF Official Embedding (PCA RGB)              ← 预计算 64D → PCA → RGB
Row 4: |Student - AEF| 差异热图                      ← 逐像素 MAE
```

- Planet 跳过填充帧（全 0 帧不显示，若全为填充则跳过该源）
- Landsat 标题标注 `[30m→10m]` 提示低分辨率上采样
- PCA 使用统一基（以 AEF 做 SVD，Student 用同一套基投影）

### 4. 投影头（Stem）权重固定

**用户观点**：参考 OlmoEarth 论文，各源的独立投影头（stem/encoder bank）权重应**固定不训练**，使每次投影一致，从而更好地训练 STP（空间-时间处理）层。

**状态**：待实现。需在训练脚本中将 `model.encoder_bank`（或对应 stem 模块）的参数设为 `requires_grad=False`。

## 技术发现

### Planet 数据现状
- 实际存在 6 帧 tif（20251209 ~ 20260430）
- 但 collate_fn 统一填充到 max_t=16，frame 6-15 全为 0
- 可视化时需过滤：`frame.abs().max() > 0.001` 才显示

### Landsat 分辨率
- 原始 30m，上采样到 128×128（对应 S2 的 10m 基准）
- 空间分布不均匀：某些行非零像素仅 8/128，某些行 97/128

### 模型兼容性
- `AlphaEarthFoundations` 的 `input_sources` 为灵活字典，支持任意源名和通道数
- 但 `AEFLoss.source_configs` 需手动添加新源配置（默认 L1，weight=1.0）
