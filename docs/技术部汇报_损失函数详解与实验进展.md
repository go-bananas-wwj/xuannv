## 一、核心问题：什么是嵌入坍缩？

### 1.1 现象描述

我们训练一个自监督模型，把卫星图像编码成 128 维向量。理想情况下，不同图像应该产生**不同的**向量。但实际训练中经常出现这种情况：

- 所有图像的 embedding 几乎一样（比如全是 `[0.08, 0.08, ..., 0.08]`）
- 128 个维度中，只有 10~20 个有变化，其余 108 个维度的标准差接近 0
- 重建 loss 很低（模型"很会"重建），但 embedding 完全丧失了区分能力

这就叫 **Embedding Collapse（嵌入坍缩）**。

### 1.2 为什么会坍缩？

**根本原因：重建任务太容易作弊了。**

想象一个考试：老师要求学生"把输入的句子重写一遍"。聪明的学生发现：不管输入什么，只要输出一个"万能模板"就能得 80 分。模型也学会了这个把戏——它把 embedding 压缩成一个固定模式，decoder 记住这个模式就能重建大部分内容。

**数学上的根因：L2 归一化的 Jacobian 屏障。**

我们的 bottleneck 在输出前做 L2 归一化（`F.normalize(x, p=2, dim=1)`），把向量压到单位球面上。这个操作的 Jacobian 矩阵是 `(I - uu^T) / ||x||`。当 ||x|| 很小时，分母趋近于 0，梯度爆炸；更重要的是，当所有向量方向趋同时，`uu^T` 趋近于常数矩阵，Jacobian 几乎把梯度"杀死"——uniformity loss 的梯度无法传递到 encoder 的前层。

> 通俗理解：L2 norm 就像一个"罩子"，把向量都压到球面上。当向量已经挤在一起时，你再怎么推它们，L2 norm 都会把它们重新压回同一个点。推力的方向被"罩子"抵消了。

### 1.3 如何判断是否坍缩？

我们监控三个核心指标：

| 指标 | 含义 | 健康值 | 坍缩信号 |
|------|------|--------|---------|
| **Reconstruction Loss** | 重建误差（越小越好） | < 0.3 | — |
| **Uniformity** | embedding 分散程度（越负越好） | -4 ~ -1 | > -0.5 |
| **Active Dimensions** | 标准差 > 0.05 的维度数 | 128/128 | < 20 |

**Uniformity 的直观理解：**

> 把 128 维空间想象成一个盒子，每个 embedding 是一个小球。Uniformity = -4 意味着小球均匀铺满整个盒子，每个角落都有；Uniformity = 0 意味着所有小球挤在一个角落，完全重叠。

## 二、我们的解决方案总览

### 2.1 核心策略：训练时跳过 L2 Norm

**这是最关键的设计决策。**

```
训练时:  Conv1x1 → [pre_norm_map] → 不 L2 归一化 → 直接输出
          ↑
          └─ 所有反坍缩损失都在这个 pre-norm 空间计算

推理时:  Conv1x1 → [pre_norm_map] → L2 归一化 → VMF 噪声 → 输出
```

为什么这样有效？

- **Pre-norm 空间**：向量有原始幅度，||xi - xj|| > 0，uniformity loss 的梯度可以正常传播
- **L2 空间**：所有向量被强制压到单位球面，方向差异被"罩子"抵消

> 类比：pre-norm 空间是"开阔的草原"，你可以自由移动；L2 空间是"狭窄的管道"，你只能沿着管道壁滑动。

### 2.2 反坍缩四件套

我们在 pre-norm 空间部署了 4 类互补的反坍缩损失：

```
┌─────────────────────────────────────────────────────────────┐
│  1. Raw Uniformity Loss（核心）                              │
│     → 惩罚 embedding 挤在一起                                │
│                                                              │
│  2. Decorrelation Loss（Barlow Twins）                       │
│     → 惩罚维度之间"同涨同跌"                                 │
│                                                              │
│  3. Variance/Covariance Regularizer（VICReg）                │
│     → 约束每个维度必须有方差，且维度间不相关                  │
│                                                              │
│  4. Bottleneck Orthogonality Loss                            │
│     → 直接约束 Conv1x1 权重矩阵正交，不依赖 embedding 值     │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 辅助损失

- **Reconstruction Loss**：让模型保留图像信息（权重必须低，否则导致坍缩）
- **Temporal Contrastive Loss**：让不同时间的 embedding 产生差异
- **Teacher-Student Consistency**：保持训练/推理一致性

## 三、Bottleneck 设计：训练 vs 推理的差异

### 3.1 VMFBottleneck 核心代码

```python
class VMFBottleneck(nn.Module):
    def __init__(self, channels, embedding_dim, kappa=2000.0,
                 skip_l2_training=False):  # ← 关键参数
        ...
        self.skip_l2_training = skip_l2_training

    def forward(self, features):
        pre_norm_map = self.to_embedding(features)  # [B, D, H, W]

        # ★ 关键分支：训练时跳过 L2 Norm
        if self.training and self.skip_l2_training:
            embedding_map = pre_norm_map              # 原始幅度
            embedding_vector = embedding_map.mean(dim=(-2, -1))
        else:
            embedding_map = self._apply_norm(pre_norm_map)  # L2 + VMF
            embedding_vector = embedding_map.mean(dim=(-2, -1))
            embedding_vector = F.normalize(embedding_vector, p=2, dim=1)

        pre_norm_vector = pre_norm_map.mean(dim=(-2, -1))
        return embedding_map, embedding_vector, pre_norm_vector, pre_norm_map
```

### 3.2 为什么 `skip_l2_training=True` 能阻止坍缩？

**L2 Norm 的 Jacobian 屏障：**

L2 归一化：`y = x / ||x||`

Jacobian 矩阵：`J = (I - yy^T) / ||x||`

当 ||x|| 很小时，分母 → 0，梯度爆炸。更关键的是，当所有 y 趋同时（y ≈ 常向量），`yy^T` 是一个接近常数的矩阵，`J` 几乎把所有方向的梯度分量都投影掉了。

**直观类比：**

> 想象一群人站在一个山坡上。L2 norm 就像一个"强制让所有人站在同一个海拔高度"的规则。当大家都挤在一个点时，你推其中一个人，L2 规则会立刻把他拉回原位——你的推力被"规则"抵消了。
>
> Pre-norm 空间没有这条规则，你可以自由推，推力真正生效。

### 3.3 Active Dimensions 在哪里计算？

**明确答案：在 pre-norm 空间计算。**

```python
with torch.no_grad():
    if use_spatial_vicreg and gathered_spatial_map is not None:
        spatial_flat_diag = gathered_spatial_map.permute(0,2,3,1).reshape(-1, D)
```

- `gathered_spatial_map` 来自 `pre_norm_map`
- `all_pre` 来自 `pre_norm_embedding`
- **阈值 0.05**：一个维度的标准差 > 0.05 才算"活跃"
- 当前所有实验都是 **128/128**，零坍缩

## 四、损失函数逐个详解

### 4.1 Raw Uniformity Loss（核心改进）

**目标**：让所有 embedding 在空间中尽可能"散开"，不要挤在一起。

#### 计算步骤

```python
def raw_uniformity_loss(embeddings):
    # Step 1: 标准化到零均值、全局单位方差
    z = embeddings - embeddings.mean(dim=0)
    global_std = z.std() + 1e-4
    z = z / global_std

    N = z.shape[0]   # batch size
    D = z.shape[1]   # 维度 (128)

    # Step 2: 自适应温度 t = 2/D
    t = 2.0 / D

    # Step 3: 计算所有样本对的欧氏距离平方
    sq_pdist = torch.cdist(z, z, p=2).pow(2)  # [N, N]

    # Step 4: 只取上三角（i < j，避免重复和自距离）
    pair_mask = torch.triu(torch.ones(N, N), diagonal=1)
    sq_pdist_pairs = sq_pdist[pair_mask]

    # Step 5: RBF 核 + logsumexp
    loss = torch.logsumexp(-t * sq_pdist_pairs, dim=0)
           - math.log(sq_pdist_pairs.shape[0])
    return loss
```

#### 通俗解释

> **核心思想**：如果所有样本都挤在一起，两两距离很小 → `exp(-t * d^2)` 很大 → logsumexp 很大 → loss 接近 0（坏）。
>
> 如果样本均匀散开，大部分距离很大 → `exp(-t * d^2)` 很小 → logsumexp 很小 → loss 为负（好）。

**为什么用 `logsumexp` 而不是直接求平均？**

因为 `logsumexp` 对"最近的邻居对"最敏感。即使 99% 的样本对距离很远，只要有 1% 的样本对挤在一起，loss 就会明显上升。这迫使模型**消除所有局部聚集**。

**值域参考：**

| Uniformity | 含义 |
|-----------|------|
| ≈ 0 | 全部坍缩到一个点（灾难） |
| -1.0 | 轻度聚集 |
| -2.0 | 中等分散（我们当前水平） |
| -3.0 | 良好分散 |
| -4.0 | 非常均匀（理想状态） |

#### 与 L2 空间 uniformity 的关键区别

```
Raw Uniformity（pre-norm 空间）:
  - 输入: 原始幅度向量 x
  - 先标准化（零均值+单位方差），但保留原始空间结构
  - 计算 ||xi - xj||²
  - 梯度直接作用于 x，无 L2 Jacobian 屏障
  - ✅ 坍缩时梯度非零

Batch Uniformity L2（L2 空间）:
  - 输入: L2 归一化后的向量 u = x/||x||
  - 计算 |ui · uj|
  - Jacobian: (I - uu^T)/||x||
  - ❌ 坍缩时 ||x||→0，梯度爆炸或消失
```

### 4.2 Decorrelation Loss（Barlow Twins）

**目标**：惩罚维度之间的相关性，让每个维度独立变化。

#### 计算步骤

```python
def decorrelation_loss(embeddings):
    # Step 1: 标准化到零均值单位方差
    z = embeddings - embeddings.mean(dim=0)
    std = z.std(dim=0) + 1e-4
    z = z / std

    N = z.shape[0]

    # Step 2: 互相关矩阵 C = (Z^T · Z) / N  [D, D]
    c = (z.T @ z) / N

    D = c.shape[0]

    # Step 3: 对角线 = 1（标准化保证），非对角线 = 0（去相关）
    on_diag = (c.diagonal() - 1).pow(2).sum() / D
    off_diag = c.pow(2).sum() / D - c.diagonal().pow(2).sum() / D

    return on_diag + off_diag
```

#### 通俗解释

> 想象一个 128×128 的表格，每个格子 [i, j] 表示"维度 i 和维度 j 的相关程度"。
>
> - 对角线应该是 1（自己和自己的相关性）
> - 非对角线应该是 0（不同维度不应该同步涨跌）
>
> 如果维度 3 和维度 7 总是同时变大或变小，说明它们在说"同一件事"，浪费了一个维度。

**为什么叫 Barlow Twins？**

> 因为原版 Barlow Twins 用两个 view（同一张图的两个增强版本）计算互相关矩阵，然后让互相关矩阵接近单位矩阵。我们简化为单 view 版本。

### 4.3 Variance Regularizer（VICReg）

**目标**：强制每个维度必须有足够的方差，防止"僵尸维度"。

#### 计算步骤

```python
def variance_regularizer(embeddings, min_std=1.0):
    std = torch.sqrt(embeddings.var(dim=0, unbiased=False) + 1e-4)
    return F.relu(min_std - std).mean()
```

#### 通俗解释

> 想象 128 个温度计。如果其中 100 个始终显示 25.0°C（方差=0），它们就是"僵尸"——占着位置但不提供任何信息。
>
> 这个 loss 说：每个温度计的标准差必须 ≥ min_std，否则就惩罚。
>
> `F.relu(min_std - std)` 的意思是：只有 std < min_std 时才产生惩罚，std ≥ min_std 时惩罚为 0。

**为什么 `min_std=1.0`？**

这是经验值。128 维 embedding 的 std 通常在 0.5~2.0 之间，设 1.0 是合理的"及格线"。

### 4.4 Covariance Loss（VICReg）

**目标**：惩罚维度之间的协方差，与 decorrelation 互补。

#### 计算步骤

```python
def covariance_loss(embeddings):
    N = embeddings.shape[0]
    emb_centered = embeddings - embeddings.mean(dim=0, keepdim=True)

    # 协方差矩阵
    cov = (emb_centered.T @ emb_centered) / (N - 1)

    # 只惩罚非对角线元素
    off_diag = cov - torch.diag(torch.diag(cov))
    return (off_diag ** 2).mean()
```

#### 与 Decorrelation 的区别

| | Decorrelation | Covariance |
|--|---------------|------------|
| 先标准化？ | ✅ 是（零均值单位方差） | ❌ 否 |
| 计算的是 | 相关系数（[-1, 1]） | 协方差（原始尺度） |
| 对角线约束 | 强制 = 1 | 不约束 |
| 互补性 | 标准化后去相关 | 原始尺度去相关 |

两者一起用：decorrelation 保证"方向独立"，covariance 保证"尺度也独立"。

### 4.5 Bottleneck Orthogonality Loss

**目标**：直接约束 Conv1x1 权重矩阵的行向量正交，从源头防止坍缩。

#### 计算步骤

```python
def bottleneck_orthogonality_loss(weight):
    W = weight.reshape(weight.shape[0], -1)  # [out_dim, in_dim]
    W_norm = F.normalize(W, p=2, dim=1)      # 每行归一化

    # Gram 矩阵: G[i,j] = W[i] · W[j]
    gram = W_norm @ W_norm.T  # [D, D], 对角线 = 1

    D = gram.shape[0]

    # 只惩罚非对角元素（维度间相关性）
    off_diag = (gram.pow(2).sum() - D) / (D * (D - 1))
    return off_diag
```

#### 通俗解释

> 想象 Conv1x1 是一个"筛选器"，从输入特征中筛选出 128 个维度。如果筛选器的第 3 行和第 7 行几乎一样，那么无论输入什么，输出中维度 3 和维度 7 也会几乎一样。
>
> 这个 loss 说：筛选器的每一行必须是"正交"的——就像 XYZ 坐标轴，互相垂直，互不重叠。
>
> **最大优点**：不依赖 embedding 的实际值。即使 embedding 已经坍缩了，这个 loss 仍然有梯度（因为它约束的是权重矩阵本身）。

**Gram 矩阵的直观：**

> G[i, j] = 0 意味着"第 i 个筛选方向和第 j 个方向垂直"（好）。
> G[i, j] = 1 意味着"两个方向完全相同"（坏，浪费了一个维度）。

### 4.6 Reconstruction Loss（重建损失）

**目标**：让模型保留输入图像的信息，不能乱编。

#### 计算步骤

```python
def reconstruction_loss(prediction, target, target_mask, recon_mask=None):
    pixel_valid_mask = (~torch.isnan(target)).float()
    mask = target_mask[:, :, None, None, None].float() * pixel_valid_mask

    # 可选：MAE 掩码（只重建被 mask 的区域）
    if recon_mask is not None:
        mask = mask * recon_mask

    diff = torch.abs(prediction - target) * mask
    denom = torch.clamp(mask.sum(), min=1.0)
    return diff.sum() / denom
```

#### 通俗解释

> 这是模型的"主任务"：输入一张卫星图，输出一张差不多的图。
>
> 但问题是：如果模型用"作弊"方式完成（embedding 坍缩 + decoder 硬记），重建 loss 也会很低。
>
> **所以重建权重必须控制得很低**（0.05~0.1），否则模型会为了重建 accuracy 而放弃 embedding 质量。

**为什么权重不能高？**

| recon 权重 | 结果 |
|-----------|------|
| 0.5 | 模型全力优化重建，embedding 迅速坍缩（V13 Round1 教训） |
| 0.1 | 平衡状态，重建还行，embedding 也分散 |
| 0.05 | embedding 最分散，但重建略差 |

### 4.7 Teacher-Student Consistency Loss

**目标**：保证训练时的 embedding 和推理时的 embedding 一致。

#### 计算步骤

```python
def consistency_loss(teacher, student):
    teacher = F.normalize(teacher, dim=-1)
    student = F.normalize(student, dim=-1)
    return 0.5 * (1.0 - torch.sum(teacher * student, dim=-1)).mean()
```

#### 通俗解释

> 训练时我们做了各种数据增强（随机裁剪、翻转等），同一个 patch 被增强两次产生 teacher 和 student view。
>
> 这个 loss 说：同一个 patch 的两个 view，它们的 embedding 方向应该相同（cosine similarity = 1）。
>
> `1 - cos_sim` 就是它们的角度差异。loss = 0 意味着完全一致。

**但我们 Round7 大多数实验关掉了 consistency**（因为权重 0.2 时会导致坍缩）。

### 4.8 Temporal Contrastive Loss（时序对比）

**目标**：让不同时间窗口的 embedding 产生差异。

#### 计算步骤

```python
def temporal_contrastive_loss(emb_w1, emb_w2, temperature=0.05, target_margin=0.2):
    # Global mean
    flat_w1 = emb_w1.reshape(B, D, -1).mean(dim=-1)  # [B, D]
    flat_w2 = emb_w2.reshape(B, D, -1).mean(dim=-1)
    flat_w1 = F.normalize(flat_w1, p=2, dim=-1)
    flat_w2 = F.normalize(flat_w2, p=2, dim=-1)

    cos_sim = (flat_w1 * flat_w2).sum(-1)  # [B]

    # Hinge loss: 只惩罚 cos_sim > 0.2 的部分
    loss = F.relu(cos_sim - target_margin).mean() / temperature
    return loss
```

#### 通俗解释

> 同一个地点，今年 6 月和今年 12 月的卫星图应该不一样（夏天 vs 冬天）。
>
> 这个 loss 说：两个时间窗口的 embedding 夹角应该 ≥ 78°（cos ≤ 0.2）。如果 cos_sim > 0.2，说明模型"没区分出时间差异"，就要惩罚。
>
> 为什么是 hinge loss（只惩罚超出 margin 的部分）？因为两个相邻月份的图可能真的很像，我们不想强迫它们完全不同。

### 4.9 Temporal Cosine Pixel Loss（像素级时序）

**目标**：在像素级别强制时序差异，避免"全局偏移"作弊。

#### 计算步骤

```python
def temporal_cosine_pixel_loss(emb_w1, emb_w2, temperature=0.05):
    # 每个像素位置独立 normalize
    f1 = F.normalize(emb_w1, p=2, dim=1)  # [B, D, H, W]
    f2 = F.normalize(emb_w2, p=2, dim=1)

    # 逐像素 cos_sim
    cos_map = (f1 * f2).sum(dim=1)  # [B, H, W]

    # 直接最小化所有像素的 cos_sim（非 hinge）
    loss = cos_map.mean() / temperature
    return loss
```

#### 与 Temporal Contrastive 的区别

| | Temporal Contrastive | Temporal Cosine Pixel |
|--|----------------------|----------------------|
| 粒度 | Global mean（整图一个向量） | Pixel-level（每个像素独立） |
| Loss 类型 | Hinge（达到 margin 就停） | 直接最小化（持续优化） |
| 防作弊 | 一般 | 强（不能靠全局偏移） |
| 计算量 | 小 | 大（H×W 倍） |

> 如果只用 global mean，模型可能学会"给所有像素加一个固定偏移"来产生差异——这不代表真的学到了时序变化。Pixel-level loss 迫使每个像素都产生真实差异。

### 4.10 Gap-Aware Temporal Cosine Loss（V6.5）

**目标**：根据时间间隔大小，动态设定"应该有多不同"。

#### 计算步骤

```python
def gap_aware_temporal_cosine_loss(pre_w1, pre_w2, time_gap_ms, max_gap_ms=6个月):
    f1 = F.normalize(pre_w1, p=2, dim=1)
    f2 = F.normalize(pre_w2, p=2, dim=1)
    cos_map = (f1 * f2).sum(dim=1)  # [B, H, W]

    # 根据时间 gap 设定 target
    time_gap_norm = torch.clamp(time_gap_ms / max_gap_ms, 0.0, 1.0)  # [B]
    target = 1.0 - 2.0 * time_gap_norm  # gap=0→1, gap=max→-1
    target_map = target.view(B, 1, 1).expand(B, H, W)

    # MSE: 让 cos_map 接近 target
    loss = ((cos_map - target_map).pow(2)).mean() / temperature
    return loss
```

#### 通俗解释

> 相邻两个月的图，允许比较相似（target cos = 0.5）；相隔一年的图，应该很不同（target cos = -1）。
>
> 这个 loss 不搞"一刀切"，而是根据真实时间 gap 动态调整目标。

#### 发现问题

| **L2 理论** | 0.088 | 0.05 | **56.6%** | 🟡 合理 |

> Pre-norm 空间的 std 是 L2 理论值的 **4.1 倍**，但阈值没有同步调整，导致 `128/128` 是假象。

#### 代码修正

- `src/config.py`: `TrainingConfig` 新增 `active_dims_threshold: float = 0.15`

- `configs/round7_8gpu/*.yaml`: pre-norm 实验设 0.15，L2 对照组(exp5)保持 0.05

## 六、关键发现与下一步

### 6.1 已确认的事实

1. **`skip_l2_training=True` 是阻止坍缩的充分条件**
   - V13 Round1（5/12）全部坍缩 → Round7 全部 128/128
   - 唯一变量：skip_l2_training

2. **Reconstruction 权重是反坍缩的核心杠杆**
   - recon=0.5 → 坍缩（Round1 教训）
   - recon=0.1 → 平衡
   - recon=0.05 → uniformity 最好（Exp2）

3. **Uniformity 提升主要靠训练时长，而非超参数**
   - E35 所有实验 uniformity 都趋近 -2.0
   - 超参数差异在收敛过程中被"抹平"

4. **Active Dimensions 在 pre-norm 空间计算，阈值已修正为 0.15**
   - `std_per_dim = sqrt(var(pre_norm_embedding, dim=0))`
   - **旧阈值 0.05 过于宽松**（pre-norm std_mean≈0.36，阈值仅占 14%）
   - **新阈值 0.15** 与 pre-norm 数值尺度匹配
   - 估算真实 active_dims：82-111/128（未坍塌，但活跃度有差异）

### 6.2 未回答的问题

1. **Uniformity 能否达到 -3.0？**
   - 当前 -2.0，V10 在 100epoch 达 -2.94
   - 可能需要更长训练（100+ epoch）或更大 batch

2. **训练指标好 ≠ 下游任务好**
   - AUC 尚未验证（方案 A：等 50epoch 后统一跑）
   - 历史教训：V12 AUC ≈ 0.5（时序信号被 L2 norm 毁掉）

3. **L2 空间 vs Pre-norm 空间的 AUC 对比**
   - 训练在 pre-norm，推理在 L2
   - 需要验证：pre-norm 的时序信号能否"传递"到 L2 空间
