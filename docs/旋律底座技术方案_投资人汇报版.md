## 一、项目定位与核心使命

### 1.1 什么是旋律底座？

**旋律底座**（内部代号 xuannv_embdding）是一个**遥感图像 Embedding 预训练模型**，核心能力是将任意时间、任意地点的遥感卫星图像，转化为一个紧凑的"语义指纹向量"（128维或64维）。

**下游应用场景**:
- **变化检测**: 对比两期 embedding，自动发现地表变化（建筑施工、农田转化、水域变化等）
- **地物分类**: 用 embedding 做 WorldCover、Dynamic World 等地物类型识别
- **时序分析**: 追踪同一地点多年变化趋势
- **跨模态检索**: 用文字描述搜索匹配的遥感区域

### 1.2 核心使命：解决两大行业难题

自监督预训练在遥感领域面临两个根本性难题：

| 问题 | 现象 | 后果 |
|------|------|------|
| **Embedding 坍缩** (Collapse) | 模型不管输入什么图像，都输出几乎相同的向量 | 下游任务完全失效，变化检测 AUC ≈ 0.5（随机猜测） |
| **时间敏感性缺失** (Temporal Blindness) | 模型学不到时间变化，夏天和冬天的 embedding 几乎相同 | 无法做变化检测，时序分析失效 |

**我们的定位**: 行业首个**同时解决坍缩和时间盲**的遥感 embedding 预训练方案。

### 1.3 与 AlphaEarth Foundations（AEF）的关系

- **AEF**: Google Research 2024 年发表的遥感自监督预训练论文（NeurIPS），开源了架构设计和训练思路
- **旋律底座**: 完全独立从零实现，**仅参考接口设计**，核心算法全部自研
- **关键差异**: AEF 论文未开源完整训练代码和权重，且存在严重的坍缩问题；我们不仅复现了架构，还根治了坍缩

### 2.2 云筛选预处理

S2 光学影像受云严重影响，原始数据每 patch 约 **180 帧**，但大量被云覆盖。

**筛选策略**:
1. 计算每帧的 cloud_score = 亮度/10000 - NDVI
2. 每月保留 cloud_score 最低的 **2 帧**
3. 全 cloudy 月份 fallback 保留 **1 帧**（最差情况）

**效果**:
- 原始: 29,707 帧 → 筛选后: 9,321 帧
- 每 patch: ~70 帧 → ~22 帧
- Fallback 月份: 357 / 4839 = 7.4%（主要集中在冬季 1-2 月）

### 2.3 数据归一化

每种传感器有独立的归一化流水线：

**光学源（S2/Landsat）**:
```
原始 DN 值 → 0-1 范围检测（若 max<2.0 则 ×10000 还原）
→ log(x+1)/10 对数压缩
→ z-score 标准化（减去预计算的 mean，除以 std）
→ ±6σ 裁剪（防止异常值）
```

**SAR 源（S1）**:
```
dB 值 → clip[-30, 10]（剔除极端值）
→ z-score 标准化
→ ±6σ 裁剪
```

**分类源（WorldCover/DynamicWorld）**:
```
类别索引 → one-hot 编码（WC=11类, DW=9类）
```

**统计量计算**: 对每个数据源、每个通道独立计算 mean/std，保存为 JSON。

### 2.4 内存预加载

遥感数据 I/O 是训练瓶颈（每次从磁盘读取 GeoTIFF 极慢）。

**方案**: 首次训练时多进程（16 workers）并行加载所有数据到内存，序列化为缓存文件（~27GB），后续直接从内存读取。

- 首次加载: ~4.2 分钟
- 缓存加载: ~125 秒
- DDP 安全: 仅 rank 0 写缓存，其他 rank 等待并读取

### 2.5 月度采样策略

训练时，每个样本 = **(patch_id, year, month)**，即从某个 patch 的某个月份采样。

**输入构建**:
- 当月每源加载所有可用帧（S2: 1-2帧, S1: 2-4帧, Landsat: 1-4帧）
- 超过 max_frames=32 时随机采样（云筛选后实际不会触发）
- 目标帧: 同月从输入帧中随机选 1 帧，且从输入 mask 中**排除该帧**（避免重建变成恒等复制）

**双窗口采样**（训练时）:
- 将当月所有帧的时间戳排序，中点分割为 w1 和 w2
- 支持多种模式: random_split / adjacent_month / non_overlap / mixed_scale
- 为时序对比损失提供 before/after 配对

**跨时相重建**（可选）:
- 输入 month_A，目标 month_B（|B-A| ≥ 2 个月）
- 强迫模型关注时间变化，而非仅仅空间重建

## 三、模型架构：逐模块详解

### 3.1 架构总览

```
Input: [B, S=3, T≤32, C=6, H=128, W=128]  (B=batch, S=source, T=time, C=channel)
    ↓
SensorEncoderBank        → [B, S, T, 128, 64, 64]   (每源独立编码，下采样 1/2)
    ↓
Flatten (S×T)            → [B, ≤96, 128, 64, 64]   (3源×32帧=96，展平到时间轴)
    ↓
STPEncoder (8 blocks)    → [B, ≤96, 128, 64, 64]   (三路径空间-时间-精度编码)
    ↓
时间条件摘要 (attention)  → [B, 128, 64, 64]        (window_code 查询聚合时间信息)
    ↓
VMFBottleneck            → [B, 64, 64, 64]          (Conv1×1压缩，训练skip L2)
    ↓
Decoder (逐像素MLP)       → [B, out_ch, 64, 64]     (条件解码器，逐源重建)
    ↓
F.interpolate            → [B, out_ch, 128, 128]    (上采样回原始分辨率)
    ↓
Output reconstructions
```

**总参数量**: **3.58 亿**（STPEncoder 占 3.57 亿，是绝对大头）

### 3.2 模块一：SensorEncoderBank（传感器编码器组）

**设计原则**: 只有带时间戳的图像帧作为输入。静态数据（DEM、WorldCover 等）仅作为重建目标，不输入给编码器。

**结构**（每源独立）:
```python
class SensorEncoder(nn.Module):
    # 输入: [B*T, C, 128, 128]
    adapter = Conv2d(in_channels, stem_channels, 1)  # 若通道不匹配
    stem = Conv2d(stem_channels, stem_dim, 3, stride=2, padding=1) + BatchNorm + GELU
    projection = Conv2d(stem_dim, out_dim, 1) + BatchNorm + GELU
    # 输出: [B*T, 128, 64, 64]（下采样 1/2）
```

**每源配置**:
| 源 | 输入通道 | stem_dim | out_dim |
|----|---------|----------|---------|
| S2 | 6 | 128 | 128 |
| S1 | 2 | 128 | 128 |
| Landsat | 6 | 128 | 128 |

**关键点**: S2 永不 drop（最可靠），S1/Landsat 训练时可能随机 drop（模拟缺失），增强鲁棒性。

### 3.3 模块二：Time/Window/RelativeTime Encoding（时间编码）

三个互补的时间编码器：

**TimeCodeEncoder**（绝对时间编码）:
```python
# 输入: timestamps_ms [B, T]
# 正弦编码: 归一化到年 → 1/10000^(2i/dim) 频率 → sin/cos
# MLP: dim → dim
# 输出: [B, T, 64]
```

**WindowCodeEncoder**（窗口编码）:
```python
# 输入: (valid_start_ms, valid_end_ms) [B]
# 编码: [sin(start), cos(start), sin(end), cos(end)] → MLP
# 输出: [B, 64]
# 作用: 告诉模型"当前关注哪个时间窗口"
```

**RelativeTimeCodeEncoder**（相对时间编码）:
```python
# 输入: relative_time [B, 1] 范围 [0,1)
# 正弦编码 + MLP
# 输出: [B, 16]
# 作用: decoder 条件，告诉模型"目标在什么相对位置"
```

### 3.4 模块三：STPEncoder（核心编码器，玄女V2）

这是模型的**绝对核心**，占 99.7% 参数量。

#### 设计灵感：三条独立路径 + 跨尺度交换

参考 AEF 论文 Figure 2D，我们实现了严格对齐的三路径架构：

| 路径 | 维度 | 空间分辨率 | 操作 | 作用 |
|------|------|-----------|------|------|
| **Space** | 768 | 1/16L (8×8) | ViT-style MHA | 捕捉全局空间模式（如道路网格、建筑布局） |
| **Time** | 384 | 1/8L (16×16) | 时间 MHA + 正弦时间编码 | 捕捉时序依赖（如季节变化、作物生长） |
| **Precision** | 128 | 1/2L (64×64) | 3×3 卷积 | 保留高分辨率细节（如边缘、纹理） |

**为什么三条路径？**
- 空间注意力需要极低分辨率（8×8）才能覆盖全局上下文
- 时间注意力需要中等分辨率（16×16）平衡时空计算
- 精度路径保持高分辨率（64×64）不丢失细节
- 三条路径通过**跨尺度交换**互相补充信息

#### STPBlock 内部结构

每个 block 包含：

**1. 三条路径独立计算**:
```python
space_out = SpaceOperator(space_x)      # [B,T,768,8,8]
time_out = TimeOperator(time_x, ts)     # [B,T,384,16,16]
precision_out = PrecisionOperator(precision_x)  # [B,T,128,64,64]
```

**SpaceOperator**: ViT-style 自注意力
```
[B,T,768,8,8] → permute → [B*T, 64, 768]  (64=8×8 空间位置)
→ LayerNorm → QKV Linear → Scaled Dot-Product Attention → MLP
→ permute 回来 → [B,T,768,8,8]
```

**TimeOperator**: 时间轴自注意力（+正弦时间编码注入）
```
[B,T,384,16,16] → permute → [B*16*16, T, 384]  (每个空间位置独立过时间注意力)
→ 加 sinusoidal 时间编码 → LayerNorm → QKV → Attention → MLP
→ [B,T,384,16,16]
```

**PrecisionOperator**: 3×3 卷积保持高分辨率
```
[B,T,128,64,64] → reshape → [B*T,128,64,64]
→ GroupNorm → Conv3×3 → GELU → Conv3×3 → 残差
→ [B,T,128,64,64]
```

**2. 六方向跨尺度交换（LearnedSpatialResampling）**:

这是 STPBlock 的**灵魂设计**。三条路径通过可学习的空间重采样互相传递信息：

```
Time → Space:     下采样 0.5×  (16×16 → 8×8)
Precision → Space: 下采样 0.125× (64×64 → 8×8)
Space → Time:     上采样 2×    (8×8 → 16×16)
Precision → Time: 下采样 0.25× (64×64 → 16×16)
Space → Precision: 上采样 8×   (8×8 → 64×64)
Time → Precision: 上采样 4×   (16×16 → 64×64)
```

每个方向都是可学习的 ConvTranspose2d（上采样）或 Conv2d（下采样），通过**相加**融合（非拼接，保持维度一致）。

**3. STPEncoder 整体流程**:

```python
# 初始投影
space = Conv2d(128→768) + adaptive_avg_pool2d(1/8)   # → [B*T,768,8,8]
time  = Conv2d(128→384) + adaptive_avg_pool2d(1/4)   # → [B*T,384,16,16]
precision = x_flat                                     # → [B*T,128,64,64]

# 8 个 STP blocks
for block in blocks:
    space, time, precision = block(space, time, precision, timestamps, mask)

# 最终融合: space/time 上采样回 precision 分辨率
space_up = LearnedSpatialResampling(768→128, 8×)  # → [B*T,128,64,64]
time_up  = LearnedSpatialResampling(384→128, 4×)  # → [B*T,128,64,64]
out = space_up + time_up + precision + GroupNorm   # → [B*T,128,64,64]
```

**关键参数**:
- Space dim: 768（论文 1024，已降维以适配 NPU 显存）
- Time dim: 384（论文 512，已降维）
- Precision dim: 128（与论文一致）
- Blocks: 8（论文 15，已减到 8）
- Heads: 8（每路径 8 头注意力）

### 3.5 模块四：时间条件摘要（Temporal Summarization）

STPEncoder 输出的是逐帧特征 `[B, T, 128, 64, 64]`，需要聚合为单张摘要图。

**当前实现**（全局点积注意力）:
```python
pooled = x.mean(dim=(-2,-1))              # [B,T,128] 每帧全局平均
query = summary_query(window_code)[:,None] # [B,1,128] 窗口编码作为查询
attn_scores = sum(query * pooled, dim=-1)  # [B,T]
attn = softmax(attn_scores.masked_fill(~mask, -1e9))  # [B,T]
summary = einsum("bt,btchw->bchw", attn, x)  # [B,128,64,64]

# 融入时间编码均值
summary = summary + time_to_summary(time_codes.mean(dim=1))[:,:,None,None]
```

**改进方向**: 原始 AEF 使用逐空间位置 MHA（每个 64×64 位置独立注意力），我们正在向此方向改进。

### 3.6 模块五：VMFBottleneck（VMF 瓶颈层）

这是**反坍缩的核心战场**。

**结构**:
```python
class VMFBottleneck(nn.Module):
    to_embedding = Conv2d(128, embedding_dim, kernel_size=1)  # 1×1 压缩
    
    # V10 差分模块（变化检测用）
    diff_encoder = Conv2d(2*D, D//2, 1) + GroupNorm + GELU
    change_gate = Conv2d(D//2, 1, 1)      # 输出变化概率图
    fusion = Conv2d(D + D//2, D, 1) + GroupNorm + GELU
```

**关键设计：训练时 Skip L2 Norm**:

```python
def forward(self, features):
    pre_norm_map = self.to_embedding(features)  # [B,D,64,64]
    
    if self.training and self.skip_l2_training:
        # ★ 训练时跳过 L2 归一化！保留原始幅度
        embedding_map = pre_norm_map
        embedding_vector = embedding_map.mean(dim=(-2,-1))
    else:
        # 推理时标准 L2 + VMF 噪声
        direction = F.normalize(pre_norm_map, p=2, dim=1)
        noise = randn_like(direction) * sqrt(1/kappa)
        embedding_map = F.normalize(direction + noise, p=2, dim=1)
        embedding_vector = F.normalize(embedding_map.mean(dim=(-2,-1)), p=2, dim=1)
    
    return embedding_map, embedding_vector, pre_norm_vector, pre_norm_map
```

**为什么 Skip L2 如此重要？**

L2 归一化的 Jacobian 矩阵为 `(I - uu^T)/||x||`，当 embedding 坍缩时（所有 x 指向同一方向 u），`I - uu^T` 的秩降为 D-1，梯度被**杀死在切平面内**，uniformity loss 无法推动 embedding 分散。

Skip L2 后，模型在**原始幅度空间**计算所有反坍缩损失，梯度永远非零。

### 3.7 模块六：条件解码器（ConditionDecoder）

对齐 AEF 论文 Supplemental S2.4："Implicit decoders were two-hidden-layer MLPs with a width of 512."

**结构**:
```python
class ContinuousDecoder(nn.Module):
    injector = ConditionInjector(D, window_code_dim, reltime_dim, metadata_dim)
    mlp = Sequential(
        Linear(D, 512), GELU, LayerNorm(512),
        Linear(512, 512), GELU, LayerNorm(512),
        Linear(512, out_channels),
    )
    
    def forward(self, embedding_map, window_code, relative_time, metadata):
        # 1. 条件注入（加法，非拼接）
        x = injector(embedding_map, window_code, relative_time, metadata)
        # x: [B, D, 64, 64]
        
        # 2. 逐像素 MLP（每个空间位置独立）
        x_flat = x.permute(0,2,3,1).reshape(B*64*64, D)
        out_flat = mlp(x_flat)  # [B*64*64, out_ch]
        out = out_flat.reshape(B,64,64,out_ch).permute(0,3,1,2)
        # → [B, out_ch, 64, 64]
        
        # 3. 上采样回 128×128
        return F.interpolate(out, size=(128,128), mode='bilinear')
```

**条件注入**（ConditionInjector）:
```python
# 将 window_code + relative_time + metadata 投影到 D 维，通过广播加法注入
cond = concat([window_code, relative_time, metadata])  # [B, total_cond_dim]
cond_emb = proj(cond)  # [B, D]
return embedding + cond_emb[:,:,None,None]  # 广播到空间维度
```

**7 个重建目标**:
| 目标 | 类型 | 输出通道 | 重建权重 |
|------|------|---------|---------|
| S2 | 连续 (L1) | 6 | 1.0 |
| S1 | 连续 (L1) | 2 | 1.0 |
| Landsat | 连续 (L1) | 6 | 1.0 |
| DEM | 连续 (L1) | 1 | 0.05 |
| WorldCover | 分类 (CE) | 11 | 0.5 |
| Dynamic World | 分类 (CE) | 9 | 0.5 |
| JRC Water | 连续 (L1) | 1 | 0.3 |

### 3.8 模块七：变化检测头（ChangeDetectionHead）

Backbone 训练完成后冻结，单独训练轻量级 CD Head。

**V3 版本**（当前最佳）:
```python
class ChangeDetectionHeadV3(nn.Module):
    # 输入特征: |e1-e2|, e1*e2, e1, e2  → 4D 拼接
    in_dim = embedding_dim * 4
    
    encoder = Conv2d(in_dim, hidden_dim, 3) + BN + ReLU
    res1 = Conv2d(hidden_dim, hidden_dim, 3) + BN  (残差块)
    eca = ECA(hidden_dim)  # 通道注意力
    res2 = Conv2d(hidden_dim, hidden_dim, 3) + BN  (残差块)
    out = ReLU + Conv2d(hidden_dim, hidden_dim//2, 3) + BN + ReLU + Dropout2d(0.3) + Conv2d(hidden_dim//2, 1, 1)
    
    # 总参数量: ~314K（极轻量）
```

## 四、训练策略与损失函数体系

### 4.1 训练范式：Teacher-Student + DDP

**Teacher-Student 一致性**（对齐 AEF 原文 S2.2.5）:
```
Teacher: 完整输入（无扰动），EMA 更新，不计算梯度
Student: 扰动输入（帧随机 drop / 源随机 drop / 前后截断），计算梯度
Loss: Student embedding 应该与 Teacher embedding 一致
```

**Student 扰动策略**（三阶段）:
1. **源级别 drop**: S1/Landsat 30% 概率被屏蔽（S2 永不 drop）
2. **帧级别 drop**: 三种策略随机选一种
   - 随机 mask: S2 50% 帧 drop，S1/Landsat 30% drop
   - 前段截断: 保留前半时间序列
   - 后段截断: 保留后半时间序列
3. **前后截断**: 25% 概率截掉最早或最晚 1/4 的帧

**EMA 更新**:
```python
teacher_param = 0.996 * teacher_param + 0.004 * student_param
```

**分布式训练**:
- 4-8 卡 DDP（PyTorch DistributedDataParallel）
- 后端: HCCL（华为自研，替代 NCCL）
- 梯度累积: 每 2 步更新一次（模拟更大 batch）
- 梯度裁剪: norm=1.0

### 4.2 损失函数全家桶

我们实现了 **15+ 种损失函数**，覆盖反坍缩、时序敏感性、重建三个维度。

#### 4.2.1 反坍缩损失

**Spatial VICReg（核心突破）**:
```python
# 在 GMP（全局平均池化）之前计算！
spatial_pre = pre_norm_map.permute(0,2,3,1).reshape(-1, D)  # [B×H×W, D] = [B×4096, D]
var = variance_regularizer(spatial_pre, min_std=1.0)   # 强制每维 std ≥ 1.0
cov = covariance_loss(spatial_pre)                      # 惩罚维度间相关性
```

**为什么 Spatial VICReg 有效？**
- 样本量: `[B×4096, D]` 是 `[B, D]` 的 4096 倍
- 空间多样性: 每个像素位置的 embedding 被独立约束，GMP 无法平均掉
- VICReg 方差约束: 从机制上防止维度坍缩

**Decorrelation Loss（Barlow Twins）**:
```python
# 计算 embedding 维度间的互相关矩阵
z = normalize(embeddings)  # 零均值单位方差
c = (z.T @ z) / N  # [D, D] 互相关矩阵
loss = sum((diag(c)-1)^2)/D + sum(off_diag(c)^2)/D  # 对角=1，非对角=0
```

**Bottleneck Orthogonality Loss**:
```python
# 直接约束 Conv1×1 权重矩阵的行向量正交
W = to_embedding.weight.reshape(out_dim, in_dim)
W_norm = normalize(W, dim=1)
gram = W_norm @ W_norm.T  # [D, D]
loss = sum(off_diag(gram)^2) / (D*(D-1))
```

**Batch Uniformity Loss L2**（改进版）:
```python
# All-Pairs + 空间采样 + 维度 Dropout
# 对 embedding_map [B,D,H,W] 随机采样最多 512 个空间位置
# chunk 分批计算所有 i≠j 的 |u_i · u_j|
# 维度 Dropout: 随机 mask 10% 维度，增加配对多样性
```

#### 4.2.2 时序敏感性损失

**Temporal Contrastive Loss（双窗口 hinge loss）**:
```python
# Teacher (w1) vs Student (w2) 的 global mean embedding
cos_sim = (flat_w1 * flat_w2).sum(-1)  # [B]
# 要求 cos_sim ≤ target_margin (默认 0.2，角度 ≥ 78°)
loss = ReLU(cos_sim - 0.2).mean() / temperature
```

**Temporal Cosine Pixel Loss（像素级）**:
```python
# 逐像素 cosine similarity
f1 = normalize(emb_w1, dim=1)  # [B,D,H,W]
f2 = normalize(emb_w2, dim=1)
cos_map = (f1 * f2).sum(dim=1)  # [B,H,W]

# 空间感知加权: 变化区域（差异大）被推得更远
with torch.no_grad():
    diff = abs(emb_w1 - emb_w2).mean(dim=1)  # [B,H,W]
    w = normalize(diff)  # [0,1]
    target_sim = 1.0 - 2.0 * w  # 变化区域 → -1，未变化 → 1

loss = ReLU(cos_map - target_sim).mean() / temperature
```

**Gap-Aware Temporal Cosine Loss**:
```python
# 根据时间 gap 大小设定不同 target
time_gap_norm = clamp(gap_ms / max_gap_ms, 0, 1)  # [B]
target = 1.0 - 2.0 * time_gap_norm  # gap=0→1, gap=max→-1
loss = ((cos_map - target)^2).mean() / temperature
```

**Anti-Diagonal InfoNCE**:
```python
# 核心洞察: 同一地点不同时间的 embedding 应该不同
# 所以对角线 (i,i) 当作"负样本"
logits = (flat_w1 @ flat_w2.T) / temperature  # [B, B]
labels = arange(B)
loss = cross_entropy(-logits, labels)  # 最小化对角线相似度
```

#### 4.2.3 重建损失

**掩码 L1 重建**:
```python
# 只对 target_mask=True 的源计算 loss
# 对 NaN 值做掩码（如 JRC Water 的 no-data）
# MAE 变体: 随机 mask 50% 空间像素，decoder 必须依赖 embedding 重建
loss = abs(prediction - target) * mask / mask.sum()
```

#### 4.2.4 其他损失

- **Consistency Loss**: Teacher vs Student embedding map 的空间一致性
- **Classification Loss**: WorldCover 众数标签的交叉熵（辅助监督）
- **Change Consistency Loss**: bottleneck change_score 与图像差异对齐
- **Pixel Change Supervision**: 利用两期图像差异指导 embedding 差异（无标注弱监督）

### 4.3 损失权重配置（当前最佳）

```yaml
reconstruction_weight: 0.1        # 重建（已证明 recon=0.5 会导致坍缩）
consistency_weight: 0.05          # Teacher-Student 一致性
classification_weight: 0.03       # 语义监督（WorldCover 标签）
variance_weight: 0.25             # VICReg 方差（核心反坍缩）
covariance_weight: 0.001          # VICReg 协方差（已大幅降低）
pre_norm_uniform_weight: 0.5      # Pre-norm uniformity
orthogonality_weight: 0.01        # 权重正交
temporal_cosine_pixel_weight: 0.5 # 像素级时序对比
```

**关键发现**: Reconstruction 权重是核心杠杆——recon=0.5 导致坍缩，recon=0.1 是平衡点，recon=0 纯发散可达 93/128 active dims。

### 4.4 学习率调度

- 优化器: AdamW（lr=1e-4, weight_decay=0.01）
- 调度: Cosine + Warmup
- Warmup: 10 epochs 线性升温
- 最小 lr: 1e-6
- 每 step 独立计算 lr（非每 epoch）

## 五、核心技术创新：反坍缩与时间敏感性

### 5.1 创新一：Spatial VICReg（根治坍缩）

**问题**: 传统 VICReg 在 Global Mean Pooling（GMP）后的向量上计算，将 4096 个空间位置平均为 1 个向量，消灭了空间多样性。即使空间 embedding map 是分散的，GMP 后的向量也可能坍缩。

**我们的方案**: 在 GMP **之前**的空间 map 上计算 VICReg。

```python
# ❌ 错误（AEF 原文做法）
pre_norm = student_out.pre_norm_embedding  # [B, D] ← GMP 已摧毁空间多样性
var = variance_regularizer(pre_norm)

# ✅ 正确（我们的创新）
pre_norm = student_out.pre_norm_map.permute(0,2,3,1).reshape(-1, D)  # [B×4096, D]
var = variance_regularizer(pre_norm)  # 保留全部空间多样性
```

**效果**:
- 传统方案（GMP 后）: 10 epoch → active_dims = 0（完全坍缩）
- Spatial VICReg（GMP 前）: 10 epoch → active_dims = 93/128（良好发散）

### 5.2 创新二：Skip L2 Norm（绕过梯度屏障）

**问题**: L2 归一化的 Jacobian `(I - uu^T)/||x||` 在坍缩态秩降为 D-1，uniformity loss 的梯度被杀死在切平面内。

**我们的方案**: 训练时完全跳过 L2 Norm，在 pre-norm（原始幅度）空间计算所有反坍缩损失。

```python
# 训练时
if training and skip_l2_training:
    embedding = pre_norm  # 原始幅度，无归一化
    
# 推理时
else:
    embedding = L2_normalize(pre_norm)  # 标准球面 embedding
```

**效果**: uniformity loss 的梯度永远非零，因为幅度差异被保留。

### 5.3 创新三：双窗口时序对比（学习时间方向）

**问题**: 同月自重建让模型学到"时间不重要"——输入和目标同月，模型只需学空间重建。

**我们的方案**:
1. 训练时将时间序列中点分割为 w1/w2 两个窗口
2. 要求 w1 和 w2 的 embedding **不同**（hinge loss: cos_sim ≤ 0.2）
3. 引入 gap-aware: 时间 gap 越大，要求差异越大
4. 像素级约束: 每个空间位置独立约束，避免"全局偏移"作弊

**效果**: Before/After cosine distance 从 0.03 → 0.58（19 倍提升）。

### 5.4 创新四：条件解码器 + 跨时相重建

Decoder 通过 window_code 和 relative_time 条件注入，学会"什么时间该重建什么"。

跨时相重建时：
- 输入 month_A 的 S2 帧
- 目标 month_B 的 S2 帧（B ≠ A）
- Decoder 必须利用 embedding 中的时间信息来生成 month_B 的图像
- 这迫使 embedding **必须编码时间信息**

- 证明 embedding 包含丰富的变化信息，只是 cosine distance 这种线性度量无法捕捉

- 轻量 2-layer Head（314K 参数）
- K=20 shot: AUC = 0.67-0.68
- 与完整 CD Head 相比损失约 0.15 AUC
