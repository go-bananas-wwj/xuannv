## 一、项目概述

### 1.1 目标

在海淀区320个patch数据上，训练一个**完全独立的**多源遥感嵌入底座。该底座通过**极端困难的多源重建任务**迫使模型学习高质量的图像语义表征，同时输出64维embedding供下游任务使用。

### 1.2 核心设计哲学

> **"如果模型能在绝大多数信息被抹除的情况下，仍然重建出原始图像，那么它必定掌握了图像的深层语义结构，而不仅仅是记住了像素分布。"**

参考OlmoEarth的发现：遥感数据在空间、时间、模态上高度冗余，普通mask策略（如MAE的75% patch mask）对于多模态数据仍然过于简单。必须设计**多层嵌套的mask策略**，让模型无法从任何单一维度"作弊"。

### 1.3 与玄女AEF的关系

- **完全独立**：不继承、不修改 `src/models/` 下的任何类
- **数据复用**：复用 `data_raw/haidian/scenes/` 和 `statistics/haidian/` 的数据和统计量
- **蒸馏借用**：训练时可加载预训练的AEF模型（64维），其embedding作为蒸馏目标
- **评估复用**：训练完成后可用 `scripts/eval/` 中的评估脚本验证embedding质量

## 三、模型架构

模型代号：`HaidianReconEncoder`（简称HRE）

### 3.1 总体架构图

```
输入层 (4源 × 时序)
    │
    ├── 各源独立 Stem (Patch Embedding)
    │      ├── tianyi_sar: 1ch → embed_dim
    │      ├── s2: 6ch → embed_dim
    │      ├── landsat: 6ch → embed_dim
    │      └── planet: 4ch → embed_dim
    │
    ├── 时间编码 (Sinusoidal / Learnable)
    ├── 模态编码 (Learnable, per-source)
    └── 位置编码 (2D Sinusoidal 或 Learnable)
    │
    ▼
Token序列 [B, N_tokens, embed_dim]
    │
    ▼
Transformer Encoder (L层, 自注意力)
    │   - 注意力覆盖所有token（跨空间、跨时间、跨模态）
    │
    ▼
Bottleneck → 64维 Embedding
    │   - 空间维度：Global Average Pooling 或 可学习query
    │   - 可选：Conv1x1降维 + L2归一化
    │
    ├──→ 64维 Embedding输出 [B, 64] （用于下游任务）
    │
    ▼
Transformer Decoder (M层, 交叉注意力)
    │   - Query: 被mask区域的learnable mask token + 条件编码
    │   - KV: Encoder输出的visible token
    │
    ▼
多源重建头 (Per-source MLP)
    │   - 每个源一个独立的重建head
    │   - 输入：decoder输出 + 模态条件 + 时间条件
    │
    ▼
重建输出 [B, N_sources, C_source, H, W]
```

### 3.2 各模块详细规格

#### 3.2.1 输入层 — 多源Patch Embedding (`MultiSourcePatchEmbed`)

```python
class MultiSourcePatchEmbed(nn.Module):
    """
    为每个源独立做Patch Embedding。
    输入分辨率可能不同，统一通过patch_size和stride处理。
    """
    def __init__(
        self,
        source_channels: dict[str, int],      # {"s2": 6, "landsat": 6, ...}
        embed_dim: int = 256,                  # 统一token维度
        patch_size: int = 8,                   # patch大小（像素）
        image_size: int = 128,                 # 输入图像尺寸
    ):
        # 每个源一个Conv2d: (C, embed_dim, kernel=patch_size, stride=patch_size)
        # 输出: [B, embed_dim, H//patch_size, W//patch_size]
        # 然后flatten为token序列
```

**设计要点**：
- 不同源使用**独立的卷积权重**（不共享），因为各源物理意义完全不同
- 若某源分辨率与image_size不同，先通过`F.interpolate`上/下采样到`image_size`
- 输出序列长度：`N_patches = (image_size // patch_size) ** 2`
- 每个时间步的每个源产生`N_patches`个token

#### 3.2.2 编码层 — 时间/模态/位置编码

```python
class TokenEncoder(nn.Module):
    """
    为每个token添加时间、模态、位置信息。
    """
    def __init__(
        self,
        embed_dim: int = 256,
        num_sources: int = 4,
        max_timesteps: int = 48,   # > 天仪SAR最大帧数44
    ):
        # 模态编码: nn.Embedding(num_sources, embed_dim)
        # 时间编码: Sinusoidal位置编码 或 nn.Embedding(max_timesteps, embed_dim)
        # 2D位置编码: Sinusoidal (H, W) 或 可学习参数 (N_patches, embed_dim)
```

**编码加法**：`token = patch_embed + modality_embed + time_embed + pos_embed`

#### 3.2.3 Transformer Encoder (`HREncoder`)

```python
class HREncoder(nn.Module):
    """
    标准Transformer Encoder，跨所有token做自注意力。
    """
    def __init__(
        self,
        embed_dim: int = 256,
        num_layers: int = 8,
        num_heads: int = 8,
        mlp_ratio: float = 4.0,
        dropout: float = 0.1,
        use_gradient_checkpointing: bool = True,
    ):
        # 每层: LayerNorm → MultiHeadAttention → LayerNorm → MLP
        # 使用Pre-Norm结构（更稳定）
```

**关键设计**：
- **Pre-Norm**（LN在attention/MLP之前）：训练更稳定
- **跨模态注意力**：所有token（无论来源、时间步）都在同一个序列中，注意力天然覆盖跨模态、跨时间关系
- **Gradient Checkpointing**：若NPU内存紧张，可启用以时间换空间

#### 3.2.4 Bottleneck — 64维Embedding (`HRBottleneck`)

```python
class HRBottleneck(nn.Module):
    """
    将Encoder输出的高维token压缩为64维全局embedding。
    """
    def __init__(
        self,
        embed_dim: int = 256,
        output_dim: int = 64,
        bottleneck_method: str = "gap_mlp",  # "gap_mlp" | "query_attn" | "conv1x1_gap"
    ):
        # 方案A: gap_mlp
        #   - 对所有token做Global Average Pooling: [B, N, D] → [B, D]
        #   - MLP: [B, D] → [B, 64]
        #   - L2归一化（可选，训练时可skip）
        #
        # 方案B: query_attn (推荐)
        #   - 可学习query: [1, 1, 64]
        #   - CrossAttention: query attend to all encoder tokens
        #   - 输出: [B, 64]
```

**推荐**：方案B（Query Attention），因为：
- 相比GAP，query attention可以自适应地关注重要token
- 与AEF的bottleneck逻辑类似，便于后续AEF蒸馏
- 输出天然适合作为decoder的条件向量

#### 3.2.5 Transformer Decoder (`HRDecoder`)

```python
class HRDecoder(nn.Module):
    """
    为被mask的token预测重建值。
    使用交叉注意力：Query为mask token，KV为encoder输出的visible token。
    """
    def __init__(
        self,
        embed_dim: int = 256,
        num_layers: int = 4,
        num_heads: int = 8,
        mlp_ratio: float = 4.0,
    ):
        # 每层: LayerNorm → CrossAttention(encoder_output, mask_token) → LayerNorm → MLP
        # mask_token: 可学习参数 [1, 1, embed_dim]，每个被mask位置都使用相同的初始mask token
```

**输入条件**：
- Query：`mask_token + pos_embed + modality_embed + time_embed`
- Key/Value：Encoder输出的所有visible token

#### 3.2.6 多源重建头 (`HRReconstructionHead`)

```python
class HRReconstructionHead(nn.Module):
    """
    将decoder输出的token映射回像素空间。
    每个源一个独立的head（因为通道数不同）。
    """
    def __init__(
        self,
        embed_dim: int = 256,
        source_channels: dict[str, int],
        patch_size: int = 8,
        image_size: int = 128,
    ):
        # 对每个源:
        #   ConvTranspose2d(embed_dim, source_channels, kernel=patch_size, stride=patch_size)
        #   或 MLP: [B, N_patches, embed_dim] → [B, N_patches, patch_size*patch_size*C] → reshape
```

**输出形状**：`[B, C_source, H, W]`，与原始输入分辨率一致

### 3.3 完整前向流程伪代码

```python
def forward(self, batch):
    """
    batch: {
        "tianyi_sar": [B, T, 1, H, W],      # T为时间步数（聚合后）
        "s2": [B, T, 6, H, W],
        "landsat": [B, T, 6, H, W],
        "planet": [B, T, 4, H, W] 或 None,
        "timestamps": [B, T],                # 时间编码用
        "modality_mask": dict,               # 各模态的mask配置
    }
    """
    # 1. 应用Mask（见第4章）
    masked_batch, mask_info = self.apply_masking(batch)

    # 2. Patch Embedding
    all_tokens = []  # list of [B, N_tokens_source_t, embed_dim]
    for source_name in SOURCE_ORDER:
        if masked_batch[source_name] is None:
            continue
        tokens = self.patch_embed[source_name](masked_batch[source_name])
        tokens = self.token_encoder(tokens, source_id=SOURCE_ORDER.index(source_name))
        all_tokens.append(tokens)

    # 3. 拼接所有token
    tokens = torch.cat(all_tokens, dim=1)  # [B, N_total, embed_dim]

    # 4. Encoder
    encoder_output = self.encoder(tokens)  # [B, N_visible, embed_dim]

    # 5. Bottleneck → 64维Embedding
    embedding = self.bottleneck(encoder_output)  # [B, 64]

    # 6. Decoder（仅解码被mask的token）
    mask_tokens = self.create_mask_tokens(mask_info)  # [B, N_masked, embed_dim]
    decoder_output = self.decoder(mask_tokens, encoder_output)  # [B, N_masked, embed_dim]

    # 7. 重建头
    reconstructions = {}
    for source_name in SOURCE_ORDER:
        if source_name not in mask_info["decode_sources"]:
            continue
        recon = self.recon_heads[source_name](
            decoder_output[mask_info["source_to_decoder_indices"][source_name]]
        )
        reconstructions[source_name] = recon  # [B, C, H, W]

    return {
        "embedding": embedding,           # [B, 64]
        "reconstructions": reconstructions,
        "mask_info": mask_info,
    }
```

## 四、困难重建策略（核心）

### 4.1 为什么普通Mask不够？

OlmoEarth论文指出：遥感数据存在三重冗余——
1. **空间冗余**：邻近像素高度相关
2. **时间冗余**：相邻时间步变化缓慢
3. **模态冗余**：SAR与光学、不同光学源之间存在物理对应关系

因此，即使mask掉75%的patch，模型仍可能通过空间插值、时间复制、模态交叉推断等"捷径"完成任务，无需真正理解语义。

### 4.2 四层嵌套Mask策略

本架构采用**四层嵌套mask**，从粗粒度到细粒度剥夺模型的信息来源：

#### Layer 1: 模态级Mask（Modality Dropout）

每个训练样本，随机决定每个模态的角色：

| 角色 | 概率 | 是否输入Encoder | 是否作为重建目标 | 目的 |
|------|------|----------------|-----------------|------|
| `NOT_SELECTED` | 0.10 | ❌ | ❌ | 模拟真实缺失，训练鲁棒性 |
| `ENCODE_ONLY` | 0.25 | ✅ (masked) | ❌ | 提供上下文，但不监督 |
| `DECODE_ONLY` | 0.25 | ❌ | ✅ | 强迫模型从其他模态推断 |
| `ENCODE_AND_DECODE` | 0.40 | ✅ (masked) | ✅ (masked部分) | 标准MAE模式 |

**关键约束**：
- 每个样本至少要有**1个**`ENCODE_ONLY`或`ENCODE_AND_DECODE`模态（否则encoder无输入）
- 每个样本至少要有**1个**`DECODE_ONLY`或`ENCODE_AND_DECODE`模态（否则无监督信号）
- `DECODE_ONLY`模态是完全隐藏的——模型看不到该模态的任何像素，必须从其他模态的时空上下文推断

#### Layer 2: 时间步Mask（Temporal Dropout）

对于输入encoder的模态（`ENCODE_ONLY`和`ENCODE_AND_DECODE`）：
- 随机mask掉**50%**的时间步
- 被mask的时间步完全不可见（所有patch都被隐藏）
- 这强迫模型不依赖"时间复制"捷径

#### Layer 3: Patch级Block Mask（Spatial Masking）

对于输入encoder的可见时间步：
- 将`image_size x image_size`分成`patch_size x patch_size`的block
- 随机保留**25%**的block可见，**75%**被mask（MAE标准）
- 使用**随机采样block**（非网格化），增加多样性

#### Layer 4: 通道级Mask（Channel Dropout）

对于输入encoder的可见patch：
- 在每个patch内部，随机mask掉**50%**的通道
- 例如S2的6个通道中，随机选3个置零
- 这强迫模型不依赖单模态内的通道冗余

### 4.3 Mask后的信息剩余率计算

假设一个样本有4个模态，每个模态1个时间步（简化计算）：

| Mask层 | 条件 | 信息剩余率 |
|--------|------|-----------|
| 模态级 | 2个模态为DECODE_ONLY（不可见） | 50%模态可见 |
| 时间步 | 50%时间步被mask | 25%模态×时间可见 |
| Patch级 | 25% patch可见 | 6.25% 原始token可见 |
| 通道级 | 50%通道可见 | **3.125%** 原始信息可见 |

**结论**：模型必须从不到4%的原始信息中重建96%的内容。这是一个极端困难的任务，足以杜绝任何捷径。

### 4.4 Mask实现伪代码

```python
def apply_four_layer_mask(self, batch):
    """
    对batch应用四层嵌套mask。
    返回masked_batch和mask_info（用于decoder和loss计算）。
    """
    B, T = batch["tianyi_sar"].shape[:2]
    mask_info = {
        "modality_roles": {},
        "decode_sources": [],
        "temporal_mask": {},
        "spatial_mask": {},
        "channel_mask": {},
    }

    # Layer 1: 模态级角色分配
    roles = ["NOT_SELECTED", "ENCODE_ONLY", "DECODE_ONLY", "ENCODE_AND_DECODE"]
    probs = [0.1, 0.25, 0.25, 0.4]

    for source in SOURCE_ORDER:
        # 若该源数据为None（如Planet缺失），强制设为NOT_SELECTED
        if batch[source] is None:
            mask_info["modality_roles"][source] = "NOT_SELECTED"
            continue

        role = np.random.choice(roles, p=probs)
        mask_info["modality_roles"][source] = role

    # 约束检查：确保至少1个encode源和1个decode源
    encode_sources = [s for s, r in mask_info["modality_roles"].items()
                      if r in ("ENCODE_ONLY", "ENCODE_AND_DECODE")]
    decode_sources = [s for s, r in mask_info["modality_roles"].items()
                      if r in ("DECODE_ONLY", "ENCODE_AND_DECODE")]

    if len(encode_sources) == 0:
        # 强制随机选一个模态为ENCODE_AND_DECODE
        # ...（实现细节）
    if len(decode_sources) == 0:
        # 强制随机选一个模态为DECODE_ONLY
        # ...（实现细节）

    # Layer 2-4: 对encode源应用时间/空间/通道mask
    masked_batch = {}
    for source in SOURCE_ORDER:
        role = mask_info["modality_roles"][source]
        x = batch[source]  # [B, T, C, H, W]

        if role == "NOT_SELECTED":
            masked_batch[source] = None
            continue

        if role == "DECODE_ONLY":
            # 完全不输入encoder
            masked_batch[source] = None
            mask_info["decode_sources"].append(source)
            continue

        # role为ENCODE_ONLY或ENCODE_AND_DECODE
        # Layer 2: 时间步mask
        temporal_mask = torch.ones(B, T, dtype=torch.bool)
        n_keep = max(1, T // 2)
        keep_indices = torch.randperm(T)[:n_keep]
        temporal_mask[:, keep_indices] = False  # False = masked
        mask_info["temporal_mask"][source] = temporal_mask
        x_masked = x.clone()
        x_masked[temporal_mask] = 0  # masked时间步置零

        # Layer 3: Patch级block mask（仅在keep的时间步上应用）
        spatial_mask = self.generate_block_mask(
            H=image_size, W=image_size, patch_size=patch_size, visible_ratio=0.25
        )  # [H, W], 1=可见, 0=masked
        mask_info["spatial_mask"][source] = spatial_mask
        x_masked = x_masked * spatial_mask[None, None, None, :, :]  # broadcast

        # Layer 4: 通道级mask（仅在可见的patch上应用）
        C = x.shape[2]
        n_keep_ch = max(1, C // 2)
        keep_channels = torch.randperm(C)[:n_keep_ch]
        channel_mask = torch.zeros(C, dtype=torch.bool)
        channel_mask[keep_channels] = True  # True = 可见
        mask_info["channel_mask"][source] = channel_mask
        x_masked = x_masked * channel_mask[None, None, :, None, None]

        masked_batch[source] = x_masked

        if role == "ENCODE_AND_DECODE":
            mask_info["decode_sources"].append(source)

    return masked_batch, mask_info
```

### 4.5 Decoder目标构建

Decoder需要重建的是**原始完整图像中被mask的部分**。

对于每个`decode_source`：
- 若为`DECODE_ONLY`：整个图像都是目标（encoder从未见过）
- 若为`ENCODE_AND_DECODE`：仅被Layer 2-4 mask掉的部分是目标

目标图像与重建输出的对应关系：
```python
# 对DECODE_ONLY源：
target = original_batch[source]  # [B, T, C, H, W]
reconstruction = model_output["reconstructions"][source]  # [B, T, C, H, W]
# loss = L1(reconstruction, target)

# 对ENCODE_AND_DECODE源：
target = original_batch[source]
reconstruction = model_output["reconstructions"][source]
# 仅计算被mask区域的loss
mask = ~temporal_mask & spatial_mask & channel_mask  # 被mask的位置
loss = L1(reconstruction * mask, target * mask) / mask.sum()
```

## 五、损失函数

### 5.1 主损失：像素级重建损失 (`L_recon`)

```python
def reconstruction_loss(model_output, original_batch, mask_info):
    total_loss = 0
    total_pixels = 0

    for source in mask_info["decode_sources"]:
        pred = model_output["reconstructions"][source]
        target = original_batch[source]

        if mask_info["modality_roles"][source] == "DECODE_ONLY":
            # 整个图像是目标
            loss = F.l1_loss(pred, target, reduction="sum")
            n_pixels = target.numel()
        else:  # ENCODE_AND_DECODE
            # 仅计算被mask区域
            mask = compute_combined_mask(mask_info, source)  # [B, T, C, H, W]
            loss = F.l1_loss(pred * mask, target * mask, reduction="sum")
            n_pixels = mask.sum()

        total_loss += loss
        total_pixels += n_pixels

    return total_loss / (total_pixels + 1e-8)
```

**权重**：`w_recon = 1.0`（绝对主力）

### 5.2 辅助损失1：AEF蒸馏损失 (`L_distill`)

加载预训练的AEF模型（如`aef_embeddings`目录下的模型或已有checkpoint），将其64维embedding作为软目标。

```python
def aef_distillation_loss(hre_embedding, aef_embedding):
    """
    hre_embedding: [B, 64] — 本模型输出
    aef_embedding: [B, 64] — AEF模型对同一输入的输出
    """
    # L2归一化后计算均方误差
    hre_norm = F.normalize(hre_embedding, p=2, dim=-1)
    aef_norm = F.normalize(aef_embedding, p=2, dim=-1)
    return F.mse_loss(hre_norm, aef_norm)
```

**权重**：`w_distill = 0.01 ~ 0.05`（轻量辅助，不可喧宾夺主）

**实现说明**：
- AEF模型在训练时冻结，不参与梯度更新
- 仅在AEF模型对当前输入能成功输出embedding时计算此loss
- 若AEF模型无法处理某些源（如Planet），可跳过该样本的蒸馏loss

### 5.3 辅助损失2：Embedding推散损失 (`L_uniform`)

防止64维embedding坍缩到相同方向。

```python
def uniformity_loss(embeddings):
    """
    embeddings: [B, 64]
    参考Wang & Isola 2020的RBF uniformity loss。
    """
    z = F.normalize(embeddings, p=2, dim=-1)
    sq_pdist = torch.cdist(z, z, p=2).pow(2)
    # 只算上三角（排除对角线）
    mask = torch.triu(torch.ones(B, B, device=z.device), diagonal=1).bool()
    loss = torch.logsumexp(-2.0 * sq_pdist[mask], dim=0) - math.log(mask.sum())
    return loss
```

**权重**：`w_uniform = 0.01`（极轻量，仅作为保险）

### 5.4 总损失

```python
L_total = w_recon * L_recon + w_distill * L_distill + w_uniform * L_uniform
```

**设计意图**：
- `L_recon`是绝对的训练主力（权重1.0），模型必须通过极端困难的重建任务学习语义
- `L_distill`提供AEF的先验知识引导，帮助模型快速收敛到合理的embedding空间
- `L_uniform`是最后的保险丝，防止embedding全部坍缩到同一方向

### 6.2 训练流程

```python
# train.py 主循环
for epoch in range(epochs):
    for batch in dataloader:
        # 1. 前向传播
        output = model(batch)

        # 2. AEF蒸馏（若启用）
        aef_emb = None
        if aef_model is not None:
            with torch.no_grad():
                aef_emb = aef_model(batch)  # 需适配输入格式

        # 3. 计算损失
        loss_recon = reconstruction_loss(output, batch, output["mask_info"])
        loss_distill = aef_distillation_loss(output["embedding"], aef_emb) if aef_emb is not None else 0
        loss_uniform = uniformity_loss(output["embedding"])

        loss = w_recon * loss_recon + w_distill * loss_distill + w_uniform * loss_uniform

        # 4. 反向传播
        loss.backward()
        clip_grad_norm_(model.parameters(), grad_clip_norm)
        optimizer.step()
        optimizer.zero_grad()

        # 5. 日志
        if step % log_every == 0:
            log(f"epoch={epoch} step={step} recon={loss_recon:.4f} distill={loss_distill:.4f} uniform={loss_uniform:.4f}")

    # 6. 评估与保存
    if epoch % eval_every == 0:
        evaluate_reconstruction(model, val_dataloader)
        evaluate_embedding(model, val_dataloader)  # kNN等

    if epoch % save_every == 0:
        save_checkpoint(model, optimizer, epoch)
```

2. **Embedding质量**（验证语义保留）：

3. **收敛监控**：

   - 蒸馏loss应逐渐下降（模型向AEF对齐）

## 九、关键设计决策记录

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 架构独立性 | 基于AEF修改 / 完全独立 | **完全独立** | 用户明确要求，避免玄女架构的复杂度干扰重建任务 |
| Embedding维度 | 32 / 64 / 128 / 768 | **64** | 与AEF对齐，便于蒸馏；下游任务已验证64维有效 |
| 重建空间 | 像素空间 / Latent空间 | **像素空间** | 实现简单，监督信号明确，适合小数据量 |
| Mask策略 | 单层patch mask / 多层嵌套 | **四层嵌套** | 参考OlmoEarth，杜绝捷径 |
| 模态角色分配 | 固定 / 随机 | **随机** | 增加多样性，训练鲁棒性 |
| Decoder结构 | 共享head / Per-source head | **Per-source** | 各源物理特性差异大，独立head更合理 |
| Bottleneck方式 | GAP / Query Attention | **Query Attention** | 更灵活，与AEF类似 |
| 时间编码 | Sinusoidal / Learnable | **Sinusoidal** | 更稳定，无需学习 |
| 损失组合 | 纯重建 / 重建+蒸馏+推散 | **重建+轻量蒸馏+轻量推散** | 重建为主，其他辅助 |
| AEF蒸馏权重 | 0.0 / 0.01 / 0.1 / 1.0 | **0.02** | 轻量引导，不可喧宾夺主 |
| 是否保留地图重建目标 | 是 / 否 | **否** | 纯自重建，输入=输出 |
