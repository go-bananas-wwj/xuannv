## 二、数据预处理阶段（离线，训练前执行）

### 2.1 S2 云筛选

**脚本**: `scripts/preprocessing/filter_cloudy_frames.py`

**流程**：
1. 遍历每个 patch 的 S2 目录下所有 `.tif`
2. 对每个帧计算 `cloud_score = brightness/10000 - NDVI`
3. 按自然月分组
4. 每月保留 cloud_score 最低的 **2 帧**
5. 若该月全部 cloudy，fallback 保留 **1 帧**（最不清的那张）
6. 输出到新目录 `harbin_scenes_cloud_filtered/s2/`

**结果**：
- 原始 29,707 帧 → 筛选后 9,321 帧
- 平均每 patch：~22 帧（原 ~70 帧）
- fallback 月份：357 / 4839 = 7.4%（主要集中在冬季 1-2 月）

### 2.2 统计量计算

**脚本**: `scripts/preprocessing/compute_statistics.py`

**流程**：
1. 对每个源遍历所有 patch 的所有帧
2. **关键**：对 S2/Landsat 先执行 `log(x+1)/10` 变换，**再**计算 mean/std
3. 对 S1 先 `clip[-30, 10]`，再计算 mean/std
4. 输出 7 个 JSON 文件到 `/workspace/statistics/harbin_scenes/`

**示例 S2 stats** (`s2_stats.json`)：
```json
{
  "band_0": {"mean": 0.8234, "std": 0.1567},
  "band_1": {"mean": 0.7651, "std": 0.1423},
  ...
}
```

> ⚠️ 这个顺序极其重要：`normalize_data` 在加载时也先做 log 变换，再用这些统计量做 z-score。**如果统计量在 log 前计算，z-score 后 std≈0，信号全失。**

## 三、数据加载阶段（在线，每个训练 step）

### 3.1 Dataset 初始化（`HarbinPatchDataset.__init__`）

**配置**（两个实验共用 `configs/xuannv_v2.yaml` 基础）：

```yaml
data:
  manifest_path: /workspace/raw/phase1_harbin/harbin_scenes_cloud_filtered
  stats_dir: /workspace/statistics/harbin_scenes
  image_size: 128
  max_frames: 32
  num_input_sources: 3        # S2, S1, Landsat
  num_target_sources: 4       # S2, S1, Landsat, DEM
  input_sources: ["s2", "s1", "landsat"]
  target_sources:
    - {name: s2, loss_type: 0, sensor_src: s2, out_channels: 6}
    - {name: s1, loss_type: 0, sensor_src: s1, out_channels: 2}
    - {name: landsat, loss_type: 0, sensor_src: landsat, out_channels: 6}
    - {name: dem, loss_type: 0, sensor_src: null, out_channels: 1}
```

**初始化流程**：
1. `_discover_patches()`: 扫描 `manifest_path` 下所有 `patch_*` 目录 → 424 个 patch
2. `_load_stats()`: 加载 7 个 `_stats.json`
3. `_build_monthly_samples()`: **严格 2025-only**，为每个 patch 的每个月生成样本 `(patch_id, year, month)`
   - 遍历每个 patch 的每个输入源（S2/S1/Landsat）
   - 从文件名解析时间戳，按自然月分组
   - 只保留 2025 年的月份
   - 结果：`monthly_samples` 列表，每个元素 = `(patch_id, 2025, month)`
4. `_preload_all()`: **内存预加载**
   - 用 `ProcessPoolExecutor(16 workers)` 并行加载所有 patch 的所有源
   - 对每个 patch：加载输入帧（S2/S1/Landsat）+ 目标帧（DEM 等静态数据）
   - 缓存到 `/workspace/outputs/.cache_shared/dataset_cache_{hash}.pt`
   - DDP 下 rank 0 负责加载并保存缓存，其他 rank 等待并读取
   - 缓存大小：约 27-32 GB

### 3.2 `__getitem__` / `_get_item` 详细流程

每个样本 = `(patch_id, year=2025, month)`，返回一个 dict。

#### Step 1: 加载输入帧（当月每源）

```python
for s_idx, src_name in enumerate(["s2", "s1", "landsat"]):
    frames, ts = _load_monthly_frames(patch_id, src_name, 2025, month)
```

`_load_monthly_frames` 内部：
1. 从预加载缓存或磁盘读取该 patch 该源的所有帧
2. 过滤时间戳在 `[month-01 00:00:00, month-last_day 23:59:59]` 范围内的帧

**帧数限制**（超 `max_frames=32` 时）：
- **训练**：`random.sample(range(n_avail), 32)` — 随机选 32 帧
- **验证**：`step = n_avail / 32`，等间距采样

**示例**：某 patch 的 S2 在 2025-05 有 3 帧，S1 有 4 帧，Landsat 有 2 帧：
- `source_frames` shape: `[3, 32, 6, 128, 128]`
- `source_mask`: 只有前 3/4/2 个位置为 True
- `source_input_mask`: `[True, True, True]`

#### Step 2: 构建目标帧

**目标源**：S2(6ch), S1(2ch), Landsat(6ch), DEM(1ch)

```python
target_res = H  # = 128，与输入同分辨率
target_images shape: [4, max(6,2,6,1, 11), 128, 128] = [4, 11, 128, 128]
```

**动态目标（S2/S1/Landsat）**：
- **同月重建**（默认）：从输入帧中 `random.choice` 1 帧作为目标
- **关键修复**：将该帧从 `source_mask` 中设为 False，`source_frames` 对应位置置 0
  - 目的：避免模型直接复制输入帧完成重建
  - 退化：当月只有 1 帧时不排除
- **跨月重建**（prob=0 时关闭）：从 `month_B` 加载目标帧

**静态目标（DEM）**：
- 从缓存/磁盘读取单张 TIFF
- `read_tif(..., image_size=0)` — 读取原始尺寸
- `normalize_data` → `_resize_to_target(data, 128)`
- `target_relative_time = 0.5`（静态时间偏移）

#### Step 3: 归一化流水线（`normalize_data`）

**S2（光学）**：
```
原始 TIFF → read_tif (bilinear resize 到 128×128)
    ↓
if max < 2.0: data *= 10000.0   ← 0-1 范围检测（大庆/海淀修复）
    ↓
data = log(clip(data, 0, None) + 1) / 10.0
    ↓
z-score: (data[c] - mean[c]) / std[c]   ← 用预计算统计量
    ↓
clip(data, -6.0, 6.0)
```

**S1（SAR）**：
```
原始 TIFF → read_tif (bilinear resize 到 128×128)
    ↓
clip(data, -30.0, 10.0)          ← dB 值裁剪
    ↓
z-score: (data[c] - mean[c]) / std[c]
    ↓
clip(data, -6.0, 6.0)
```

**DEM**：
```
read_tif(..., image_size=0)      ← 读取原始尺寸
    ↓
z-score（无 log 变换）
    ↓
_resize_to_target(data, 128)     ← bilinear 到 128×128
```

#### Step 4: 空间增强（训练时）

```python
if random.random() < 0.5:
    source_frames = source_frames[..., ::-1, :].copy()   # 水平翻转 (W轴)
    target_images = target_images[..., ::-1, :].copy()
if random.random() < 0.5:
    source_frames = source_frames[..., ::-1].copy()       # 垂直翻转 (H轴)
    target_images = target_images[..., ::-1].copy()
```

> 输入和目标同步翻转，地理对齐性保持。

#### Step 5: 双时间窗口采样

```python
ts_sorted = sorted(all_monthly_ts)
w1_start, w1_end, w2_start, w2_end = _sample_dual_windows(ts_sorted)
```

默认模式 `"random_split"`：
- 将当月所有时间戳排序，中点分割
- `w1 = [ts[0], ts[mid-1]]`, `w2 = [ts[mid], ts[-1]]`

其他模式（当前基线未启用）：
- `mixed_scale`: 长间隔(≥6月)或短间隔(1-3月)
- `adjacent_month`: 相邻两个月
- `non_overlap`: 非重叠长间隔

## 四、模型前向传播（最细粒度）

### 4.1 整体架构概览

```
Input: [B, S=3, T=32, C=6, H=128, W=128]
    ↓
SensorEncoderBank        → [B, S, T, 128, 64, 64]
    ↓
Flatten (S×T)            → [B, 96, 128, 64, 64]
    ↓
STPEncoder (8 blocks)    → [B, 96, 128, 64, 64]
    ↓
时间条件摘要 (attention)  → [B, 128, 64, 64] (summary_map)
    ↓
VMFBottleneck            → [B, 64, 64, 64] (embedding_map)
    ↓
Decoder (逐像素 MLP)      → [B, out_ch, 64, 64]
    ↓
F.interpolate            → [B, out_ch, 128, 128]
    ↓
Output reconstructions
```

**参数量**（实际运行值）：
- Total: **3.58 亿**
- STPEncoder: **3.57 亿**（占 99.6%）

> 对比论文原始：space_dim=1024, time_dim=512, 15 blocks → 9.93 亿。当前已缩小到 space=768, time=384, **8 blocks** → 3.58 亿，避免 OOM。

### 4.2 Sensor Encoder Bank（`src/models/sensor_encoders.py`）

**每个源独立编码器**（`SensorEncoder`）：

```
Input: [B*T, C_in, 128, 128]
    ↓
adapter (可选 1×1 Conv)   → [B*T, C_stem, 128, 128]
    ↓
stem: Conv3×3(stride=2)   → [B*T, stem_dim=128, 64, 64]
      + BatchNorm + GELU
    ↓
projection: Conv1×1       → [B*T, out_dim=128, 64, 64]
      + BatchNorm + GELU
    ↓
Output: [B*T, 128, 64, 64]
```

**SensorEncoderBank 组装**：
```python
for s_idx in range(S):
    frames = source_frames[:, s_idx, :, :, :, :]   # [B, T, 6, 128, 128]
    frames = frames.reshape(B * T, 6, 128, 128)    # [B*T, 6, 128, 128]
    enc = encoder(frames)                           # [B*T, 128, 64, 64]
    enc = enc.reshape(B, T, 128, 64, 64)            # [B, T, 128, 64, 64]
```

**输出**: `encoded` shape `[B, S=3, T=32, 128, 64, 64]`

### 4.3 Flatten 到统一序列

```python
frames = encoded.reshape(B, S * T, 128, 64, 64)     # [B, 96, 128, 64, 64]
timestamps = source_timestamps_ms.reshape(B, S * T)  # [B, 96]
mask = (effective_frame_mask & source_input_mask).reshape(B, S * T)  # [B, 96]
```

> **关键设计**：多源帧展平为单一时间序列。TimeOperator 在 96 个"时间步"上做 attention，不同源通过 `timestamps_ms` 的正弦编码区分。这是 AEF 论文原始设计。

### 4.4 STP Encoder（`src/models/blocks.py`）

#### 4.4.1 初始投影到三条路径

```python
# Space path: 128 → 768, 下采样到 1/16L (8×8)
space = Conv1x1(128→768)(x_flat)                     # [B*96, 768, 64, 64]
space = F.adaptive_avg_pool2d(space, (8, 8))         # [B*96, 768, 8, 8]
space = space.reshape(B, 96, 768, 8, 8)              # [B, 96, 768, 8, 8]

# Time path: 128 → 384, 下采样到 1/8L (16×16)
time = Conv1x1(128→384)(x_flat)                      # [B*96, 384, 64, 64]
time = F.adaptive_avg_pool2d(time, (16, 16))         # [B*96, 384, 16, 16]
time = time.reshape(B, 96, 384, 16, 16)              # [B, 96, 384, 16, 16]

# Precision path: 保持 1/2L (64×64)
precision = x_flat.reshape(B, 96, 128, 64, 64)       # [B, 96, 128, 64, 64]
```

#### 4.4.2 单个 STPBlock（循环 8 次）

```
Input:
  space:    [B, 96, 768, 8, 8]
  time:     [B, 96, 384, 16, 16]
  precision:[B, 96, 128, 64, 64]
    ↓
┌─────────────────────────────────────────────────────┐
│ 各路径独立计算                                       │
├─────────────────────────────────────────────────────┤
│ SpaceOperator:                                       │
│   reshape: [B, 96, 768, 8, 8] → [B*96, 64, 768]     │
│     (8×8=64 个空间位置，每个位置 768-dim)             │
│   LayerNorm + QKV(768→2304) + MHA(8 heads) + MLP    │
│   reshape 回来 → [B, 96, 768, 8, 8]                 │
├─────────────────────────────────────────────────────┤
│ TimeOperator:                                        │
│   + sinusoidal time encoding (timestamps_ms)         │
│   reshape: [B, 96, 384, 16, 16] → [B*256, 96, 384]  │
│     (16×16=256 个空间位置，每个位置过 96 个时间步)     │
│   LayerNorm + QKV(384→1152) + MHA(8 heads) + MLP    │
│   frame_mask 屏蔽无效帧（softmax 前 -inf）            │
│   NaN 防护：全 -inf 行替换为 0                       │
│   reshape 回来 → [B, 96, 384, 16, 16]               │
├─────────────────────────────────────────────────────┤
│ PrecisionOperator:                                   │
│   reshape: [B, 96, 128, 64, 64] → [B*96, 128, 64, 64]│
│   GroupNorm + Conv3×3(128→512) + GELU               │
│   GroupNorm + Conv3×3(512→128) + 残差               │
│   reshape 回来 → [B, 96, 128, 64, 64]               │
└─────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────┐
│ 6 方向跨尺度交换 (LearnedSpatialResampling)          │
├─────────────────────────────────────────────────────┤
│ Space ← Time:    Conv2d(384→768, k=3, s=2, p=1)     │
│   下采样 2×: 16×16 → 8×8                            │
│ Space ← Precision: Conv2d(128→768, k=15, s=8, p=7)  │
│   下采样 8×: 64×64 → 8×8                            │
│ Time ← Space:    ConvTranspose2d(768→384, k=4, s=2) │
│   上采样 2×: 8×8 → 16×16                            │
│ Time ← Precision: ConvTranspose2d(128→384, k=4, s=2)│
│   上采样 2× + bilinear 补 2×: 64×64 → 16×16         │
│ Precision ← Space: ConvTranspose2d(768→128, k=4,s=2)│
│   上采样 2× + bilinear 补 4×: 8×8 → 64×64           │
│ Precision ← Time: ConvTranspose2d(384→128, k=4,s=2) │
│   上采样 2× + bilinear 补 2×: 16×16 → 64×64         │
├─────────────────────────────────────────────────────┤
│ 融合：各路径接收其他两路信息后直接相加                │
│   space_out = space_2d + time_to_space + precision_to_space │
│   time_out  = time_2d + space_to_time + precision_to_time   │
│   precision_out = precision_2d + space_to_precision + time_to_precision │
└─────────────────────────────────────────────────────┘
```

#### 4.4.3 最终融合

```python
# Space 上采样回 64×64
space_up = ConvTranspose2d(768→128, k=4, s=2)(space_flat)   # [B*96, 128, 16, 16]
space_up = F.interpolate(space_up, (64, 64))                  # [B*96, 128, 64, 64]

# Time 上采样回 64×64
time_up = ConvTranspose2d(384→128, k=4, s=2)(time_flat)      # [B*96, 128, 32, 32]
time_up = F.interpolate(time_up, (64, 64))                   # [B*96, 128, 64, 64]

# 三条路径相加 + GroupNorm
out = space_up + time_up + precision_flat                     # [B*96, 128, 64, 64]
out = GroupNorm(out)
out = out.reshape(B, 96, 128, 64, 64)                        # [B, 96, 128, 64, 64]
```

### 4.5 时间条件摘要（`model.py:196-207`）

```python
pooled = x.mean(dim=(-2, -1))           # [B, 96, 128]  每帧全局平均
query = summary_query(window_code)       # [B, 128] → [B, 1, 128]
attn_scores = sum(query * pooled, dim=-1) # [B, 96]
attn_scores = attn_scores.masked_fill(~mask, -1e9)  # 屏蔽无效帧
attn = softmax(attn_scores, dim=-1)      # [B, 96]
summary = einsum("bt,btchw->bchw", attn, x)  # [B, 128, 64, 64]

# ★ 将逐帧时间编码融入空间摘要（替代了之前的 dummy 操作）
time_summary = time_codes.mean(dim=1)     # [B, time_code_dim=64]
summary = summary + time_to_summary(time_summary)[:, :, None, None]  # broadcast
```

- `time_to_summary`: `nn.Linear(64, 128)`
- 这是真正的信息融合，而非之前的 `time_codes.sum() * 0.0` dummy

### 4.6 VMF Bottleneck（`src/models/bottleneck.py`）

```python
pre_norm_map = Conv1x1(128→64)(summary_map)    # [B, 64, 64, 64]

if self.training and self.skip_l2_training:
    # ExpA (skipL2): 跳过 L2 Norm，保留原始幅度
    embedding_map = pre_norm_map
    embedding_vector = embedding_map.mean(dim=(-2, -1))   # [B, 64]
else:
    # ExpB (noSkipL2): 标准 L2 归一化 + VMF 噪声
    embedding_map = F.normalize(pre_norm_map, p=2, dim=1)   # [B, 64, 64, 64]
    if training and kappa > 0:
        noise = randn_like(embedding_map) * sqrt(1/kappa)   # VMF 噪声
        noisy = embedding_map + noise
        embedding_map = F.normalize(noisy, p=2, dim=1)      # 重新归一化
    embedding_vector = embedding_map.mean(dim=(-2,-1))      # [B, 64]
    embedding_vector = F.normalize(embedding_vector, p=2, dim=1)

pre_norm_vector = pre_norm_map.mean(dim=(-2,-1))        # [B, 64]
```

**输出**：
- `embedding_map`: `[B, 64, 64, 64]` — ExpB: L2 归一化；ExpA: 原始幅度
- `embedding`: `[B, 64]` — 全局平均
- `pre_norm_map`: `[B, 64, 64, 64]` — 原始空间，未归一化
- `pre_norm_embedding`: `[B, 64]` — 原始空间，全局平均

> **AB 测试核心差异**：ExpB 训练时即 L2 归一化（论文做法），ExpA 跳过 L2（保留幅度，避免 Jacobian 梯度屏障）。

### 4.7 Decoder（`src/models/decoders.py`）

#### 4.7.1 条件注入

```python
cond = cat([window_code, relative_time, metadata], dim=-1)  # [B, 64+16+4=84]
cond_emb = proj(cond)                                        # [B, 64]
embedding = embedding + cond_emb[:, :, None, None]           # broadcast 加法
```

> 条件通过**加法**注入，非拼接。MLP 输入维度保持 `embedding_dim=64`。

#### 4.7.2 逐像素 MLP

```python
# ContinuousDecoder
Input: [B, 64, 64, 64]
    ↓
permute + reshape: [B*64*64, 64]
    ↓
Linear(64 → 512) + GELU + LayerNorm
    ↓
Linear(512 → 512) + GELU + LayerNorm
    ↓
Linear(512 → out_ch)
    ↓
reshape + permute: [B, out_ch, 64, 64]
```

每个空间位置 `(h, w)` 的 64-dim embedding 独立过 MLP，输出 `out_ch` 个重建值。

#### 4.7.3 上采样回到原始分辨率

```python
if dec_h != 128 or dec_w != 128:
    flat_recon = F.interpolate(flat_recon, size=(128, 128),
                                mode='bilinear', align_corners=False)
```

**最终 reconstruction**: `[B, T_tgt=1, max_ch=11, 128, 128]`

## 五、损失计算（训练器 `ddp_xuannv_v2_trainer.py`）

### 5.1 前向流程

**Teacher forward**（无梯度）：
- 输入：原始 batch（无扰动）
- valid_period：w1（双窗口的第一窗口）
- 输出：`teacher_out.embedding_map` `[B, 64, 64, 64]`

**Student forward**：
- 输入：`_build_student_view()` 扰动后的 batch
- valid_period：batch 原始 valid_start/end
- 输出：`student_out`（embedding + reconstruction）

### 5.2 Student View 扰动策略

```
Stage 1: 源级别 drop
  - S2 (s_idx=0): 永不 drop
  - S1/Landsat: 30% 概率 drop 整个源
  - 如果某个 batch 所有源都被 drop，回退保留 S2

Stage 2: 三种策略选一种（随机）
  strat=0: 帧级别随机 drop
    - S2: 50% 概率 drop 每帧
    - S1/Landsat: 30% 概率 drop 每帧
  strat=1: 截断后半段（只保留时间上前半段）
  strat=2: 截断前半段（只保留时间上前半段）

Stage 3: 前后段截断
  - front_drop_prob=15%: 砍掉最前面 25% 的帧
  - back_drop_prob=15%: 砍掉最后面 25% 的帧
```

> 目的：Teacher 看到完整序列，Student 看到残缺序列，Consistency loss 迫使模型对输入扰动鲁棒。

### 5.3 Loss 逐项计算

#### 5.3.1 Reconstruction Loss

```python
recon = compute_recon_loss(
    predictions=student_out.reconstructions,    # [B, 1, 11, 128, 128]
    target=batch["target_images"],               # [B, 1, 11, 128, 128]
    target_mask=batch["target_mask"],            # [B, 1] bool
    target_loss_type=batch["target_loss_type"],  # [B, 1] int64
)
# 内部: |pred - target| * mask / mask.sum  (L1)

# 源特定权重
weights = source_recon_weights[target_source_idx]   # [1.0, 1.0, 1.0, 0.05]
recon = base_loss * weights.mean()
```

**权重**: `reconstruction_weight=1.0`

#### 5.3.2 Consistency Loss（Teacher vs Student）

```python
consist = consistency_loss_spatial(
    teacher_out.embedding_map.detach(),     # [B, 64, 64, 64]
    student_out.embedding_map,              # [B, 64, 64, 64]
)
# 内部:
teacher = F.normalize(teacher_map, dim=1)   # L2 归一化
student = F.normalize(student_map, dim=1)   # L2 归一化
sim = sum(teacher * student, dim=1)         # [B, 64, 64] cosine similarity
loss = 0.5 * (1.0 - sim).mean()             # (1-cos)/2 球面距离
```

**权重**: `consistency_weight=0.15`

> **关键修复**（commit `7dc77aa`）：`consistency_loss_spatial` 恢复了 `F.normalize`。在 ExpA (skipL2) 中 embedding_map 未归一化，若不 normalize 会导致 `cos_sim > 1`，loss 为负数。

#### 5.3.3 Uniformity Loss（所有像素）

```python
emb_map = student_out.embedding_map         # [B, 64, 64, 64]
# all_gather across GPUs → [B_total, 64, 64, 64]
# ExpB: B_total = 4 * 3 = 12; ExpA: B_total = 4 * 4 = 16

# 展平空间: [B_total, 64, 4096] → 采样 4096 个空间位置
# → [B_total, 64, 4096] → permute → [B_total*4096, 64]

# L2 归一化
x = F.normalize(x, p=2, dim=-1)             # [N, 64]

# 维度 Dropout: 随机 mask 10% 维度
mask = bernoulli(0.9)
x_dropped = F.normalize(x * mask, dim=-1)

# All-Pairs chunk 计算
chunk_size = 1024
for i_start in range(0, N, chunk_size):
    chunk = x_dropped[i_start:i_start+1024]   # [1024, 64]
    sim = chunk @ x_dropped.T                  # [1024, N]
    # 排除对角线
    for local_i in range(chunk_size):
        sim[local_i, global_i] = 0.0
    total_loss += sim.abs().sum()

l2_uniform = total_loss / n_pairs             # 均值，越小越好
```

**权重**: `batch_uniformity_weight=0.1`

> 值域：0 = 完美均匀，1 = 完全坍缩。良好训练应在 0.1~0.3 范围。

#### 5.3.4 VICReg Variance（Pre-norm 空间）

```python
pre_norm = student_out.pre_norm_embedding     # [B, 64]
# all_gather → [B_total, 64]
# Memory Bank enqueue + get_all → [B_total+K, 64], K=512
all_pre = cat([gathered_pre, bank_emb], dim=0)  # 最大 [16+512, 64] = [528, 64]

var = variance_regularizer(all_pre.float(), min_std=1.0)
# 内部:
std = sqrt(var(dim=0, unbiased=False) + 1e-4)   # [64] 每维标准差
var = ReLU(1.0 - std).mean()                     # 小于 1.0 的维度产生惩罚
```

**权重**: `variance_weight=0.3`

#### 5.3.5 VICReg Covariance（Pre-norm 空间）

```python
cov = covariance_loss(all_pre.float())
# 内部:
cov_matrix = (emb_centered.T @ emb_centered) / (N-1)   # [64, 64]
off_diag = cov_matrix - diag(diag(cov_matrix))         # 去除对角线
cov = (off_diag ** 2).mean()                            # 非对角线元素平方均值
```

**权重**: `covariance_weight=0.1`

#### 5.3.6 Total Loss

```python
recon_warmup = min(1.0, (epoch + 1) / 10)   # 10 epoch warmup

total = (
    recon_w * recon_warmup * recon           # 1.0 * warmup * recon
    + consist_w * consist                    # 0.15 * consist
    + var_w * var                            # 0.3 * var
    + cov_w * cov                            # 0.1 * cov
    + l2_uniform_w * l2_uniform              # 0.1 * l2unif
    + cls_w * cls                            # 0 (classification disabled)
    + decorr_w * decorr                      # 0
    + orth_w * orth                          # 0
)
```

> **修复**（commit `41a9386`）：`inter_var` 不再在 `total` 中重复加（已融入 `var`）。

### 5.4 诊断指标（每 step 打印）

```python
active_dims = (std_per_dim > 0.15).sum()     # 空间有效维度数
inter_active = (inter_std > 0.15).sum()       # 样本间有效维度
std_mean = std_per_dim.mean()                 # 平均标准差
```

### 5.5 Backward & Optimizer Step

```python
total = total / accum_steps                    # 1 (grad accum=1)
total.backward()

if (step + 1) % accum_steps == 0:
    clip_grad_norm_(model.parameters(), 1.0)   # 梯度裁剪

    # NaN/Inf 梯度检查
    for p in model.parameters():
        if p.grad is not None and (isnan(p.grad) or isinf(p.grad)):
            has_nan_grad = True
            break

    if has_nan_grad:
        optimizer.zero_grad()                   # 跳过这一步
    else:
        optimizer.step()                         # AdamW 更新
        optimizer.zero_grad()

    update_teacher()                             # EMA: teacher = 0.996*teacher + 0.004*student
```

## 九、当前已知问题与风险

1. **Spatial active dims 极低（2-6/64）** → **embedding 空间坍缩严重**
   - 64 维中只有 2-6 维有有效方差，其余维度几乎为常数
   - 这意味着 embedding 实际上活在 2-6 维子空间中

2. **L2 uniformity 持续上升（0.27→0.50~0.66）** → **均匀性在恶化**
   - 0.5+ 已经属于较严重的坍缩范围
   - 目标应在 0.1~0.3

3. **VICReg var ~0.93 接近饱和** → **variance 约束可能过强**
   - min_std=1.0 对 64 维 embedding 来说可能过高
   - 如果 pre_norm 空间的自然 std < 1.0，VICReg 会强行拉大，可能干扰其他 loss

4. **Reconstruction weight 1.0 + VICReg 0.3** → **重建和反坍缩的 balance 可能不当**
   - 当前 recon ~0.07 看似不错，但 consist 也很低
   - 模型可能在"欺骗"：用少量有效维度完成重建，其余维度被 VICReg 强制拉平

5. **3.58 亿参数 + 8 blocks** → **虽然比 9.93 亿小，但仍可能优化困难**
   - STPEncoder 占 99.6% 参数
   - 如果梯度主要流向前几层，深层可能学不到东西
